# n8n 中文文档

本仓库用于维护 `n8n-io/n8n-docs` 的简体中文译文，供 `docs.n8ndoc.com` 的 Docusaurus 新站使用。本站是社区中文翻译项目。

本批锁定版本的 1,497 个文件已写入中文译文，包括正文、目录、复用片段和生成式 API 参考；11 个更新记录文件按要求保留英文。请以 `translation-status.json` 中的来源与译文登记为准，不能仅凭文件存在判断翻译状态。

- 官方原文版本：见 `upstream.json`。官网另外生成的 28 个 API 参考页，其英文来源保存在 `.upstream/generated-api/`，对应导出地址及哈希见该目录中的 `manifest.json`。
- 文件名及目录尽量与官方一致。
- 原始图片、动图、附件和代码示例保留。
- 代码围栏中的自然语言提示词译为中文，在状态文件的 `prose_fences` 中单独记录原文及译文哈希；程序代码和表达式仍保持原样。
- 生成式 API 参考中的 OpenAPI JSON 另通过 `openapi_fences` 逐字段登记：仅翻译已复核的 `title`、`summary`、`description` 字符串，接口路径、参数名、类型、枚举、默认值、示例数据及这些字符串之外的 JSON 原文保持一致。未完成所有说明字段的 API 文件仍不登记为已译。
- 跨章节内链使用对应文件的相对路径；原英文章节锚点保留。
- 更新记录 `docs/changelog/**` 按要求保留英文。
- 原文中有明确文档证据的说明和语法笔误修正，记录在 `source-corrections.json`；上游英文快照保持原样。
- URL 映射、检查脚本及检查报告放在现有 `n8n-content` 网站工程的 `content-mapping/` 与 `scripts/docs/` 中。

`translated` 表示译文已写入并记录来源版本。本批目录及复用片段也已完成；正式发布仍需格式转换、Docusaurus 页面渲染、浏览器及部署后的链接验收。当前阶段完成的是内容准备和源文件级验证，新站尚未发布。

本仓库保留锁定上游版本的 `LICENSE.md` 原文。已翻译文件带有修改说明。请以该许可证实际内容为准，不以网站程序的许可证替代文档许可。
