# 为 n8n 作贡献 <a id="contribute-to-n8n"></a>

你可以根据自己的技能和兴趣，以多种方式为 n8n 作贡献。每种形式的贡献对 n8n 都有价值。

## 表达支持：评价 n8n <a href="#share-some-love-review-us" id="share-some-love-review-us"></a>

* 在 [GitHub](https://github.com/n8n-io/n8n) 和 [Docker Hub](https://hub.docker.com/r/n8nio/n8n) 上为 n8n 点星。
* 在 [Twitter](https://twitter.com/n8n_io)、[LinkedIn](https://www.linkedin.com/company/28491094) 和 [Facebook](https://www.facebook.com/n8nio/) 上关注 n8n。
* 在 [AlternativeTo](https://alternativeto.net/software/n8n-io/) 和 [Alternative.me](https://alternative.me/n8n-io) 上为 n8n 投票。
* 在 [Stackshare](https://stackshare.io/n8n) 上将 n8n 加入你的技术栈。
* 在 [G2](https://www.g2.com/products/n8n/reviews) 和 [Capterra](https://www.capterra.com/p/198028/n8n-io/) 上撰写 n8n 评价。

## 贡献代码 <a href="#contribute-to-the-code" id="contribute-to-the-code"></a>

你可以通过以下方式为 n8n 代码库作贡献：

* 修复 GitHub 上报告的[问题](https://github.com/n8n-io/n8n/issues)。[CONTRIBUTING 指南](https://github.com/n8n-io/n8n/blob/master/CONTRIBUTING.md)可以帮助你在几分钟内准备好开发环境。
* 为已有的第三方集成添加功能。
* 为 n8n 添加新功能。

## 贡献文档 <a href="#contribute-to-the-docs" id="contribute-to-the-docs"></a>

你可以为 n8n 文档作贡献，例如撰写节点文档或修复问题。内容类型和 PR 流程请参阅 [n8n 文档贡献指南](contribution-guide-for-n8n-docs/README.md)，写作规范请参阅 [n8n 文档风格指南](contribution-guide-for-n8n-docs/style-guide-for-n8n-docs.md)。

文档源码托管在 [n8n-docs 仓库](https://github.com/n8n-io/n8n-docs)，其中还有关于拉取请求流程的[贡献规范](https://github.com/n8n-io/n8n-docs/blob/master/CONTRIBUTING.md)。

## 贡献社区教程 <a href="#contribute-to-community-tutorials" id="contribute-to-community-tutorials"></a>

在[由社区维护、可搜索的 n8n 教程与培训资料库](https://community.n8n.io/t/how-to-share-your-tutorials/48398)中分享自己的视频或文字指南。添加标签方便他人发现，并发布到对应语言的子分类中。请遵循贡献规范，帮助资料库保持高质量，让所有人都能方便使用。

## 推荐候选人 <a href="#refer-a-candidate" id="refer-a-candidate"></a>

你是否认识适合 n8n [招聘职位](https://n8n.io/careers)的人？可以向 n8n 推荐。当推荐人选通过试用期后，n8n 会向你支付 1,000 欧元作为奖励。

具体流程：

1. **查找：**查看各职位的说明和要求，考虑认识的人中是否有合适人选。
2. **推荐：**确定潜在人选后，向 [Jobs at n8n](mailto:jobs@n8n.io) 发送邮件，主题为 _Employee referral - \[job title]_，简要介绍推荐人选及推荐理由。同时，请推荐人选通过招聘页面申请该职位。
3. **评估：**n8n 会筛选申请，并告知招聘流程的后续步骤。
4. **奖励：**推荐人选通过试用期后，n8n 会将 1,000 欧元转入你的银行账户。
