# 工作流模板创意 <a id="workflow-template-ideas"></a>

本页列出可开发为 n8n 模板库工作流模板的使用场景和建议范围。

这些创意可作为起点，也可以提交其他场景、角色和应用组合。列在本页不代表保证通过审核。

## 将创意发展为模板 <a id="develop-an-idea-into-a-template"></a>

搜索[模板库](https://n8n.io/workflows/)，了解已有内容。构建之前，明确受众、预期输入、实用输出及设置要求。

通用提示词或单个 API 调用，需要上下文和可复用逻辑才能成为实用模板。请加入场景需要的校验、匹配、分派、去重或审核逻辑，保持工作流聚焦。

对于 AI 工作流，定义模型应该做什么、如何检查其输出，以及无法提供有用答案时如何处理。

## 探索使用场景 <a id="explore-use-cases"></a>

这些示例描述的是可能的范围，并非经过测试的工作流。选择应用前，请检查服务 API、权限和依赖，自行构建并测试实现。

| 受众 | 模板创意 | 建议范围 |
| --- | --- | --- |
| 产品 | 通知团队符合条件的数据库用户 | 按明确条件筛选用户，仅将新匹配结果发送到 Slack，并记录已报告的用户。 |
| 营销、AI | 根据新 YouTube 视频起草博客 | 获取字幕，生成附有来源链接的草稿，并在发布前送审。 |
| 产品、支持、销售 | 对支持请求分类并创建跟进任务 | 对工单分类，将不确定结果送审，并创建关联任务且避免重复。 |
| 销售 | 寻找指定公司的决策者 | 读取公司列表，匹配相关岗位，记录来源，并标记缺失或不确定的匹配。 |
| AI、工程 | 根据结构化请求生成代码 | 检查请求，为明确任务生成代码，并返回检查结果和限制，供人工审核。 |
| AI、工程 | 转换矢量文件 | 接收受支持的输入格式，通过已配置服务转换文件，并报告不支持的格式或失败。 |
| AI、工程 | 在支持的语言之间转换代码 | 接收明确的源语言和目标语言，保留输入上下文，并返回带校验结果的输出供审核。 |
| 支持 | 发送 n8n 更新记录摘要 | 追踪新版本，整理相关变更并发送摘要，避免重复报告已发送版本。 |
| 销售、营销 | 从匹配的招聘信息中寻找公司 | 按岗位和地点筛选新招聘信息，对公司去重，并将来源链接保存到 Google Sheets。 |
| IT 运维 | 支持员工账号恢复 | 验证已授权的恢复请求，按要求送审，并记录结果。 |
| 产品 | 通过 Slack 命令收集产品创意 | 检查提交，将上下文保存到 Notion，并返回带有创意链接的确认消息。 |
| 销售 | 为公司列表寻找竞争对手 | 确认公司身份，收集有来源的竞争对手建议，并将不确定匹配送审。 |
| 营销 | 监测竞争对手评价 | 收集新评价，按主题分组，并发送附来源的摘要，避免重复旧评价。 |
| 销售、AI | 根据线索的社交动态起草外联消息 | 收集相关来源材料，根据材料起草消息，并要求发送前审核。 |
| 销售 | 将 Calendly 会议同步到 CRM | 将参会人与联系人匹配，创建会议记录，处理改期和取消且不重复创建事件。 |
| 营销、AI | 将客户评价转为跟进任务 | 识别可执行反馈，将每项任务关联到来源，并避免重复创建。 |
| 销售 | 将 Notion 通话笔记同步到 Pipedrive | 匹配联系人或商机，映射笔记字段，并报告无匹配记录的笔记。 |
| 营销、销售 | 为邮件订阅者评分并分派线索 | 补全订阅者信息，按明确规则评分，同步符合条件的联系人且不重复创建记录。 |
| 销售、产品、支持 | 通过 Slack 查询 CRM 联系人 | 检查请求者权限，解决歧义匹配，并仅返回允许查看的联系人字段。 |
| 工程 | 将 Freshdesk 工单同步到 Linear | 映射工单状态和负责人，关联对应记录，并防止更新在两个系统间循环。 |
| 营销、AI | 起草社交帖子并加入 Buffer 队列 | 根据明确来源材料生成帖子，送审，并将批准的版本加入队列。 |
| 销售 | 检查不活跃的 CRM 商机 | 按定义的时间段检查商机动态，标记长期未更新的记录，并确认应关闭的商机。 |
| 营销、工程、产品 | 在 Google Sheets 中合并数据源 | 标准化源字段，按稳定键合并，并报告冲突或缺失记录。 |
| IT 运维 | 移除离职员工的访问权限 | 处理已批准的离职事项，撤销指定访问权限，并记录每项成功或失败的操作。 |
| IT 运维 | 办理员工入职 | 根据已批准的员工记录创建所需资源，并报告未完成的设置。 |
| 营销 | 重新发布已批准的 WordPress 内容 | 映射为目标格式，保留来源署名，并防止重复发布。 |
| 产品 | 发送产品注册摘要 | 明确报告时间窗口和时区，计算注册总数，并包含零注册日的摘要。 |
| 产品、客户成功、支持 | 管理订阅变更 | 处理订阅事件，更新对应 CRM 记录，并处理重复或乱序通知。 |
| 销售 | 通过 Slack 更新 CRM 联系人 | 检查权限，展示拟修改内容供确认，并记录更新结果。 |
| 销售、营销、AI | 使用 AI 为新 CRM 联系人评分 | 使用明确条件和源字段，检查结构化评分，并将不确定结果送审。 |
| 销售、AI | 使用 AI 补全 Typeform 线索 | 使用可靠来源数据，保留来源信息，并标记缺乏依据的信息，而不是编造联系方式。 |
| 销售、营销、AI | 起草社交评论回复 | 对传入评论分类，起草相关回复，并将敏感或不确定回复送审。 |
| 销售 | 响应高优先级表单提交 | 检查必填字段，应用优先级规则并分派响应，同时处理重复提交。 |
| 销售、支持、营销 | 准备个性化跟进和提醒 | 根据已记录的互动起草消息，安排提醒，并在联系人回复后停止提醒。 |
| 销售、营销 | 验证并补全表格中的邮箱地址 | 检查地址，记录补全来源和置信度，并将失败与已确认结果区分。 |
| 产品、销售、客户成功、运营 | 通过 Slack 回答数据库问题 | 将查询限制为允许的读取操作，执行访问控制，并返回可追溯结果或明确失败。 |
| 营销、产品、销售 | 将网站兴趣信号分派给相应销售负责人 | 将允许使用的访客信号与 CRM 记录匹配，应用分派规则，并准备相关外联内容供审核。 |
| 销售、AI | 按职能和资历对联系人分类 | 使用明确类别，保留源字段，并将低置信度分类标记为待审核。 |
| 销售 | 追踪获得融资的公司 | 收集有来源的融资事件，确认公司身份，并仅将新匹配结果加入追踪表。 |
| 营销 | 为公司列表补充流量估算 | 匹配域名，获取明确时间段的估算数据，并报告缺失数据和服务限制。 |
| 销售 | 向销售通知高优先级线索 | 检查传入表单数据，应用明确优先级规则，并将包含 CRM 记录的通知发送给负责人。 |
| 产品、销售、AI | 将线索回复转为跟进任务 | 对传入回复分类，映射到正确商机，并创建附来源链接的下一步任务。 |
| 销售 | 使用 AI 补全公司列表 | 使用有来源的公司信息，检查输出结构，并将缺失数据与已确认事实区分。 |
| 工程、产品 | 将缺陷报告分派给正确团队 | 对问题内容分类，应用明确分派规则，并将不确定报告留待分诊。 |
| 运营、工程 | 将文件从 FTP 传输到 Google Drive | 追踪已传输文件，处理命名冲突，并报告未完成上传，避免重新上传已完成文件。 |
| 销售 | 分析目标公司的招聘活动 | 将招聘信息与指定公司匹配，汇总相关需求，并随分析保存来源链接。 |
| 营销、AI | 根据结构化内容记录起草页面 | 从不同来源记录创建有用草稿，检测重复，并要求发布前编辑审核。 |
| 营销 | 根据新产品记录起草帖子 | 选择相关源字段，创建有依据的草稿，并附原始记录链接送审。 |
| 产品 | 将产品反馈请求同步到 Linear | 映射请求字段和状态，关联对应记录，并防止重复更新或同步循环。 |
| 销售 | 补全职业档案 URL 列表 | 获取允许访问的档案数据，记录来源，并标记不可用或有歧义的档案。 |
| 销售 | 使用备用服务商验证邮箱 | 按明确顺序尝试服务商，标准化结果，并在达到文档规定的置信度后停止。 |
| 营销 | 发送邮件订阅者摘要 | 计算明确时间段内的新增量，处理空结果，并发送不暴露订阅者明细的汇总。 |
| 营销 | 将传入线索同步到 HubSpot | 检查线索字段，匹配已有联系人，创建或更新记录，并记录同步失败。 |
| 销售、客户成功 | 将 HubSpot 联系人同步到 Google Sheets | 按稳定联系人 ID 映射字段，说明同步方向，并处理更新且避免新增重复行。 |
