# 获取 n8n 帮助 <a href="#get-help-with-n8n" id="get-help-with-n8n"></a>

## 获取帮助的途径 <a href="#where-to-get-help" id="where-to-get-help"></a>

n8n 根据你的方案和问题类型提供不同的支持方式。

### n8n 社区论坛 <a href="#n8n-community-forum" id="n8n-community-forum"></a>

n8n 通过[论坛](https://community.n8n.io/)为所有 n8n 用户提供免费的社区支持。

这是寻求各类问题解答的首选渠道，n8n 支持团队和社区成员都可以提供帮助。

### 邮件支持 <a href="#email-support" id="email-support"></a>

n8n 通过 [help@n8n.io](mailto:help@n8n.io) 为以下方案提供邮件支持：

* [n8n Cloud Enterprise 和自托管 Enterprise](https://n8n.io/enterprise/) 方案可就技术、账户、账单及其他问题获得带 SLA 的邮件支持。
* 其他 [n8n Cloud 方案](https://n8n.io/pricing/)可就管理和账单问题获得邮件支持。技术支持请前往论坛。

## 求助消息中应包含的内容 <a href="#what-to-include-in-your-message" id="what-to-include-in-your-message"></a>

在论坛发帖或向客户支持发送邮件时，如果在第一条消息中说明 n8n 实例信息和遇到的问题，通常能更快获得帮助。

### n8n 实例详情 <a href="#your-n8n-instance-details" id="your-n8n-instance-details"></a>

收集 n8n 实例基本信息：

1. 打开左侧面板。
2. 选择 **Help**（帮助）。
3. 选择 **About n8n**（关于 n8n）。
4. 打开的 **About n8n**（关于 n8n）弹窗会显示当前信息。
5. 选择 **Copy debug information**（复制调试信息）。
6. 将这些信息放入论坛帖子或支持邮件中。

### 问题详情 <a href="#details-about-your-problem" id="details-about-your-problem"></a>

为更高效地解决问题，可以提供以下内容，补充上下文：

* 🎥 **截图或录屏：**简短的 Loom 视频或屏幕录制，展示实际情况。
* 📚 **相关文档：**如果已经参考过指南或文档，请在消息中附上链接。
* ☁️ **n8n Cloud 工作区（如可提供）：**联系支持时，提供 n8n Cloud 实例的工作区 URL，例如 `https://xxxxx.n8n.app.cloud`。
* 📝 **复现步骤：**按步骤简要说明出现问题前进行了哪些操作。
* 📂 **工作流或配置文件：**分享相关工作流或配置文件会很有帮助。

在消息中附上 [HAR（HTTP Archive）文件](https://en.wikipedia.org/wiki/HAR_(file_format)) 也可能有帮助。可以通过 [HAR 分析工具](https://toolbox.googleapps.com/apps/har_analyzer/)了解如何在浏览器中生成 HAR 文件，以及发布前如何隐去敏感信息。
