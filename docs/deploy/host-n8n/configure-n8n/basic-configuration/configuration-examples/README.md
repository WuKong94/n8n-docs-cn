# 配置示例 <a href="#configuration-examples" id="configuration-examples"></a>

本节提供针对特定使用场景配置 n8n 的示例。

## 本节内容 <a id="in-this-section"></a>

* [隔离 n8n](isolate-n8n.md)：阻止 n8n 实例连接到 n8n 服务器。
* [配置 Base URL](configure-the-base-url.md)：定义前端访问后端 REST API 的路径。
* [配置自定义 SSL 证书颁发机构](configure-custom-ssl-certificate-authorities.md)：连接服务时使用自签名证书。
* [设置自定义加密密钥](set-a-custom-encryption-key.md)：设置用于安全加密凭据的自定义密钥。
* [配置工作流超时](configure-workflow-timeouts.md)：设置执行超时，决定工作流最多可以运行多久。
* [指定自定义节点位置](specify-custom-nodes-location.md)：添加文件夹并指定自定义节点的路径。
* [在 Code 节点中启用模块](enable-modules-in-code-node.md)：允许 Code 节点使用内置和外部模块。
* [设置时区](set-the-timezone.md)：更改自托管实例的默认时区。
* [指定用户文件夹路径](specify-user-folder-path.md)：指定存储用户专属数据的文件夹位置。
* [配置反向代理下的 Webhook URL](configure-webhook-urls-with-reverse-proxy.md)：自定义 Webhook URL，使其兼容反向代理设置。
* [启用 Prometheus 指标](enable-prometheus-metrics.md)：启用 Prometheus 指标端点。
* [预配置 Microsoft OAuth 凭据](pre-configure-microsoft-oauth-credentials.md)：让用户无需自行注册应用即可连接。
* [配置自定义工作流模板库](configure-a-custom-workflow-templates-library.md)：设置自定义工作流模板库。
