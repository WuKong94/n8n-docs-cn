# Ask n8n AI 环境变量 <a href="#ai-assistant-environment-variables" id="ai-assistant-environment-variables"></a>

| 变量 | 类型 | 默认值 | 说明 |
| :------- | :---- | :------- | :---------- |
| `N8N_AI_ASSISTANT_BASE_URL` | String | （空） | AI 助手服务的基础 URL，指定为 `https://ai-assistant.n8n.io `。自托管 n8n 并希望启用 Ask n8n AI 时必需。 |
