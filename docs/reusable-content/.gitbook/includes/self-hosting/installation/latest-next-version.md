**Stable 与 Beta 版本**

n8n 通常每周发布一个新的次版本。`stable` 版本用于生产环境；`beta` 是最近发布的版本；`beta` 版本可能不稳定。如需报告问题，请使用[论坛](https://community.n8n.io/c/questions/12)。

当前 `stable`：2.45.5
当前 `beta`：2.46.1
{% endhint %}
