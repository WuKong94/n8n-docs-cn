<!-- 简体中文翻译；来源 n8n-io/n8n-docs；原文版本见 upstream.json。 -->

| 变量 | 类型 | 默认值 | 说明 |
| :------- | :--- | :------ | :---------- |
| `N8N_MCP_MANAGED_BY_ENV` | Boolean | `false` | 设为 `true`，通过环境变量管理 MCP 设置。当值为 `true` 时，n8n 会在每次启动时应用 MCP 变量，并锁定对应的界面控件。 |
| `N8N_MCP_ACCESS_ENABLED` | Boolean | `false` | 是否启用实例级 MCP 访问：`true` 表示启用，`false` 表示禁用。 |
