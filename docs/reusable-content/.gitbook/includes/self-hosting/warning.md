**自托管的知识要求**

自行托管 n8n 需要具备以下技术知识：

* 设置和配置服务器与容器
* 管理应用资源和扩展容量
* 保护服务器和应用的安全
* 配置 n8n

n8n 建议有经验的用户选择自托管。操作失误可能导致数据丢失、安全问题和停机。如果不熟悉服务器管理，n8n 建议使用 [n8n Cloud](https://n8n.io/cloud/)。
{% endhint %}
