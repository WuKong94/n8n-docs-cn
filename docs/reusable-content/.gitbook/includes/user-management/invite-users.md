---
title: 邀请用户
---
<!-- 简体中文翻译；来源 n8n-io/n8n-docs；原文版本见 upstream.json。 -->

现在可以邀请其他人加入 n8n 实例。

1. 使用所有者账号登录 n8n 实例。在 n8n Cloud 中，如果当前位于 Cloud 控制台，请在 **Overview（概览）**页面选择 **Open instance（打开实例）**。
2. 点击左下角用户图标旁的三点菜单，再点击 **Settings（设置）**。n8n 会打开 **Personal settings（个人设置）**页面。
3. 点击 **Users（用户）**，进入用户页面。
4. 点击 **Invite（邀请）**。
5. 输入新用户的电子邮件地址。
6. 点击 **Invite user（邀请用户）**。n8n 会发送包含加入链接的邮件。
