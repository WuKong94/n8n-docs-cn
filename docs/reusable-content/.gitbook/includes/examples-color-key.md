将模板加载到 n8n 实例的步骤如下：

1. 下载工作流 JSON 文件。
1. 在 n8n 实例中打开一个新工作流。
1. 粘贴 JSON，或选择 **Workflow menu（工作流菜单）** <img src="../assets/three-dots-horizontal.png" alt="工作流菜单图标" data-size="line"> > **Import from file...（从文件导入……）**。

示例工作流使用便笺提供指引：

* 黄色：备注和信息。
* 绿色：运行工作流的说明。
* 橙色：需要修改某些内容，工作流才能正常运行。
* 蓝色：突出展示示例中的关键功能。
