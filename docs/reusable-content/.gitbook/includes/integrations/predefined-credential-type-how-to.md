---
title: 使用预定义凭据类型
---
<!-- 简体中文翻译；来源 n8n-io/n8n-docs；原文版本见 upstream.json。 -->

使用预定义凭据类型的步骤如下：

1. 打开 HTTP Request 或 GraphQL 节点，或向工作流添加一个新节点。
2. 在 **Authentication**（身份验证）中选择 **Predefined Credential Type**（预定义凭据类型）。
3. 在 **Credential Type**（凭据类型）中选择要使用的 API。
4. 在 **Credential for `<API name>`**（对应 API 的凭据）中，可以：
    1. 选择该平台已有的凭据（如果有）。
    2. 选择 **Create New**（新建），创建新凭据。
