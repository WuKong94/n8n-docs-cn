---
title: 节点图标
---
<!-- 简体中文翻译；来源 n8n-io/n8n-docs；原文版本见 upstream.json。 -->

n8n 建议使用 SVG 作为节点图标，也可使用 PNG。如果使用 PNG，分辨率应为 60×60 像素。节点图标的宽高比应为正方形或接近正方形。

{% hint style="info" %}
**不要直接引用 Font Awesome**

如果希望在节点中使用 Font Awesome 图标，请下载图片并嵌入。不要设置 `defaults.color`：它仅用于为 Font Awesome 图标着色，n8n 3.0 会将其移除。
{% endhint %}
