* [Git](https://git-scm.com/downloads)
* Node.js 和 npm，Node 最低版本为 18.17.0。在 Linux、Mac 和 WSL 中，可按照 [nvm 安装说明](https://github.com/nvm-sh/nvm)，使用 nvm（Node Version Manager）安装两者。Windows 用户请参阅微软的 [Windows 上安装 NodeJS](https://docs.microsoft.com/en-us/windows/dev-environment/javascript/nodejs-on-windows)指南。

译注：此共用片段仍列 Node 18.17.0，而同一版本“设置开发环境”页面要求最低 Node 22.22.0。此处保留两处原文并提示差异，不据此推断所用 n8n 或开发工具版本的实际兼容范围。
