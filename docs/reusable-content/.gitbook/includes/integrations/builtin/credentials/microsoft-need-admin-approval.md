### 需要管理员批准 <a href="#need-admin-approval" id="need-admin-approval"></a>

尝试为 Microsoft360 或 Microsoft Entra 账号添加凭据时，用户可能会在操作过程中看到提示，说明此操作需要管理员批准。

当尝试为凭据授予权限的账号由 Microsoft Entra 管理时，就会出现此提示。要签发凭据，需要由管理员账号为用户（或“租户”）授予该应用的权限。

具体操作步骤请参阅 [Microsoft Entra 文档](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/grant-admin-consent)。
