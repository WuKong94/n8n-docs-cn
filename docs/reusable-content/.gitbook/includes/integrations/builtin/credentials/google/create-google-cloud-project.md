---
title: 创建 Google Cloud 项目
---
<!-- 简体中文翻译；来源 n8n-io/n8n-docs；原文版本见 upstream.json。 -->

1. 使用 Google 凭据登录 [Google Cloud 控制台](https://console.cloud.google.com)。
2. 在顶部导航中打开项目下拉菜单，选择 **New project（新建项目）**，也可以直接进入[新建项目](https://console.cloud.google.com/projectcreate)页面。
3. 输入 **Project name（项目名称）**，并选择项目的位置，即 **Organization（组织）** 和/或 **Parent resource（父级资源）**。
4. 选择 **Create（创建）**。
5. 检查顶部导航，确保项目下拉菜单已选中你的项目。如果没有，请选择刚创建的项目。
