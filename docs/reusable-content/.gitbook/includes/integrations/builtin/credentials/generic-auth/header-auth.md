## 使用请求头身份验证 <a href="#using-header-auth" id="using-header-auth"></a>

如果应用或服务支持请求头身份验证，可以使用此通用身份验证方式。

配置此凭据时，请输入：

- 需要传递给 HTTP 请求目标应用或服务的请求头 **Name（名称）**
- 该请求头的 **Value（值）**

阅读更多关于 [HTTP 请求头](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers#authentication)的说明。
