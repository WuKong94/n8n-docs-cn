**AI 工具调用中的人工参与**

此节点可以用作 AI Agent 工具调用的人工审核步骤。配置此方式后，AI Agent 会在执行需要监督的工具前暂停，并通过该服务请求人工批准。更多信息请参阅 [AI 工具调用中的人工参与](../../../../../../build/integrate-ai/ai-examples/human-in-the-loop-for-tools.md)。
