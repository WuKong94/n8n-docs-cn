**子节点中的参数解析**

使用表达式处理多个数据项时，子节点的行为与其他节点不同。

多数节点，包括根节点，可以接收任意数量的输入数据项，处理后输出结果。你可以用表达式引用输入数据项，节点会依次对每个数据项解析表达式。例如，输入包含五个 `name` 值时，表达式 `{{ $json.name }}` 会依次解析为每个名称。

在子节点中，表达式始终解析为第一个数据项。例如，输入包含五个 `name` 值时，表达式 `{{ $json.name }}` 始终解析为第一个名称。
{% endhint %}
