---
title: 操作模式
---
<!-- 简体中文翻译；来源 n8n-io/n8n-docs；原文版本见 upstream.json。 -->


此向量存储节点有四种模式：**Get Many**（获取多条）、**Insert Documents**（插入文档）、**Retrieve Documents (As Vector Store for Chain/Tool)**（检索文档，作为链或工具的向量存储）及 **Retrieve Documents (As Tool for AI Agent)**（检索文档，作为 AI 智能体工具）。所选模式决定可执行的操作，以及可用的输入和输出。
