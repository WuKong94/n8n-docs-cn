## 设置安全策略 <a id="set-the-security-policy"></a>

> 使用提供的完整对象替换实例安全策略，必须发送所有可写字段。若包含 GET 返回的只读使用数量，写入时会忽略，因此可以将 GET 响应作为 PUT 请求体提交。更新使用与界面相同的校验，并以相同方式生效。需要 \`securitySettings:manage\` 作用域，并获得个人空间策略功能许可。此配置组通过环境变量管理时，写入会以 409 拒绝，且不作任何更改；读取仍返回当前值。
