## Beta：将 n8n 包导入项目 <a id="beta-import-an-n8n-package-into-a-project"></a>

> \*\*Beta\*\*——即使不提升主版本号，也可能出现破坏性变更。\
> \
> 将 gzip 压缩的 tar 包（\`.n8np\`）导入目标项目。使用 multipart 字段 \`package\` 发送归档。可选的目标路由使用表单字段 \`projectId\` 和 \`folderId\`，省略或发送空值时使用默认值。所有可选模式／策略字段（凭据、工作流、项目、文件夹、数据表、变量和标签）在省略时均采用默认值；唯一不固定的默认值是 \`folderConflictPolicy\`，项目包中它遵循 \`projectConflictPolicy\`。必填的 \`workflowConflictPolicy\` 控制包内工作流按源 id 匹配到目标项目中的现有工作流时如何处理。最大上传大小为 \`N8N\_ENDPOINTS\_PAYLOAD\_SIZE\_MAX\` MB，默认 16。\
> \
> 包必须在 \`manifest.json\` 中声明清单，并包含清单引用的每个文件。\
> \
> 任何工作流写入之前，都会先解析凭据引用。

## Beta：将智能体、工作流、文件夹或项目导出为 n8n 包 <a id="beta-export-agents-workflows-folders-or-projects-as-an-n8n-package"></a>

> \*\*Beta\*\*——即使不提升主版本号，也可能出现破坏性变更。\
> \
> 将智能体、工作流、文件夹或整个项目导出为经 gzip 压缩的 tar\
> 归档（.n8np）。提供 \`agentIds\`/\`workflowIds\`/\`folderIds\`，或 \`projectIds\`。\
> 两组不可混用。每个导出的文件夹都包括其嵌套\
> 文件夹。启用智能体模块时，整个项目的导出会包含其智能体。\
> 显式选择智能体需要启用智能体模块。空项目仅导出\
> 项目元数据。\`versionPolicy\` 选择智能体和\
> 工作流的版本，默认为 \`latest\`。\`dependencyPolicy\` 应用于这两类实体，\
> 所需定义未包含在包中时，默认为 \`fail\`。\
> 响应以 \`application/gzip\` 流式传输，并包含 \`Content-Disposition\`\
> 附件响应头。需要获得 n8n Packages 功能许可。\
> \
> API 密钥作用域：显式选择智能体需要 \`agent:export\`。\
> 显式选择工作流或文件夹需要 \`workflow:export\`。\
> 导出整个项目只需 \`project:export\`，其中包括项目的\
> 智能体和工作流。包含的依赖项无需额外 API 密钥作用域。\
> 调用方的项目权限适用于所有包含的实体。当\
> \`includeVariableValues\` 为 true（默认），且导出实体引用变量时，\
> 还需要 \`variable:list\`；未引用变量的导出\
> 无需此作用域。\
> \
> 智能体定义包含引用的技能、自定义工具和计划。\
> 不包含知识库文件和运行时数据。智能体包导入\
> 仍不可用。<br>
