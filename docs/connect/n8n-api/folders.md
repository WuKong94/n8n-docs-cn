## 删除文件夹 <a id="delete-a-folder"></a>

> 删除项目内的文件夹。提供 \`transferToFolderId\` 时，删除之前会将工作流和子文件夹移至目标文件夹。省略时，工作流会移至项目根目录并归档，子文件夹会被删除。
