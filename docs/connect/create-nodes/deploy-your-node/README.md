# 部署节点 <a href="#deploy-a-node" id="deploy-a-node"></a>

本节介绍如何部署和分享节点。

## 本节内容 <a id="in-this-section"></a>

* [提交社区节点](submit-community-nodes.md)：将节点提交到社区节点仓库，让所有人像使用其他社区节点一样[安装和使用](../../../integrations/community-nodes/installation-and-management/README.md)。这是在 Cloud 中使用自定义节点的唯一方式。
* [安装私有节点](install-private-nodes.md)：将节点作为私有节点安装到自己的 n8n 实例。
