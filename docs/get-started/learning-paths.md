# 学习路径 <a id="learning-paths"></a>

通过 [n8n Academy](https://learn.n8n.io/) 的互动课程学习 n8n。构建实际工作流，赢取徽章，并获得结业证书。

所有课程均包含：

- 工作流实操练习
- 章节测验和结业考试
- 完成课程后颁发的徽章和证书（及格分数为 70%）
- 练习用 API（大部分课程不需要外部服务账号）

完整课程列表请参阅 [n8n Academy 课程](https://learn.n8n.io/courses)。如果想立即开始构建，请参阅[构建你的第一个工作流](build-your-first-workflow.md)。
