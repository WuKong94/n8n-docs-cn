# n8n 社区节点屏蔽名单 <a href="#n8n-community-node-blocklist" id="n8n-community-node-blocklist"></a>

n8n 维护一份社区节点屏蔽名单。名单中的节点均无法安装。

n8n 可能因多种原因将社区节点加入屏蔽名单，包括：

* 节点被故意设计为执行恶意行为。
* 节点质量过低，足以造成危害。



如果你是社区节点开发者，自己的节点被加入屏蔽名单，且认为这是误判，请联系 [hello@n8n.io](mailto: hello@n8n.io)。
