# 使用社区节点 <a href="#using-community-nodes" id="using-community-nodes"></a>

使用社区节点前，需要先[安装](installation-and-management/README.md)。

## 将社区节点添加到工作流 <a href="#adding-community-nodes-to-your-workflow" id="adding-community-nodes-to-your-workflow"></a>

安装完成后，社区节点的用法与其他节点相同。n8n 会在 **Nodes**（节点）面板的搜索结果中显示该节点，并在节点面板中用 **Package**（软件包）<img src="../.gitbook/assets/package.png" alt="软件包图标" data-size="line"> 图标标记社区节点。

## 同名社区节点 <a href="#community-nodes-with-duplicate-names" id="community-nodes-with-duplicate-names"></a>

多个社区节点可能使用相同名称。如果在工作流中使用两个同名节点，除非图标不同，否则它们看起来会一样。
