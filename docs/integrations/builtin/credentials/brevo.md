# Brevo 凭据 <a href="#brevo-credentials" id="brevo-credentials"></a>

这些凭据可用于以下节点的身份验证：

* [Brevo 节点](../app-nodes/n8n-nodes-base.brevo.md)
* [Brevo Trigger（触发器）节点](../trigger-nodes/n8n-nodes-base.brevotrigger.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Brevo](https://www.brevo.com/) 开发者账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务身份验证的更多信息，请参阅 [Brevo API 文档](https://developers.brevo.com/docs/api-key-authentication)。

## API 密钥 <a href="#api-key" id="api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：创建新密钥的方法，请参阅 [Brevo API 快速入门文档](https://developers.brevo.com/docs/getting-started#quick-start)。
