# LingvaNex 凭据 <a href="#lingvanex-credentials" id="lingvanex-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [LingvaNex](../app-nodes/n8n-nodes-base.lingvanex.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [LingvaNex](https://lingvanex.com) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Lingvanex Cloud API 文档](https://docs.lingvanex.com/reference/overview)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：在 **Account（账号）** 页面生成密钥。详细说明请参阅[在哪里获取授权密钥？](https://docs.lingvanex.com/reference/translator-service-faq#where-can-i-get-the-authorization-key)。
