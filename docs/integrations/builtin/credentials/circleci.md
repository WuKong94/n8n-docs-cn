# CircleCI 凭据 <a href="#circleci-credentials" id="circleci-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [CircleCI](../app-nodes/n8n-nodes-base.circleci.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [CircleCI](https://circleci.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- Personal API token（个人 API 令牌）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [CircleCI API 文档](https://circleci.com/docs/api/v2/index.html)。

## 使用个人 API 令牌 <a href="#using-personal-api-token" id="using-personal-api-token"></a>

配置此凭据需要：

- 一个 **Personal API Token（个人 API 令牌）**：创建方法请参阅 [CircleCI 的创建个人 API 令牌文档](https://circleci.com/docs/managing-api-tokens/#creating-a-personal-api-token)。
