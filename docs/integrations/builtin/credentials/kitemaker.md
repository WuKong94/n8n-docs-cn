# Kitemaker 凭据 <a href="#kitemaker-credentials" id="kitemaker-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Kitemaker](../app-nodes/n8n-nodes-base.kitemaker.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Kitemaker](https://www.kitemaker.co/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API access token（API 访问令牌）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Kitemaker API 文档](https://kitemakerhq.github.io/rest-docs/)。

## 使用 API 访问令牌 <a href="#using-api-access-token" id="using-api-access-token"></a>

配置此凭据需要：

- 一个 **Personal Access Token（个人访问令牌）**：在 **Manage > Developer settings（管理 > 开发者设置）** 中生成个人访问令牌。详细说明请参阅 [API 身份验证](https://kitemakerhq.github.io/rest-docs/#documentationauthentication)。
