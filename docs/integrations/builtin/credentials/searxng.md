* [SearXNG Tool（工具）](../cluster-nodes/sub-nodes/n8n-nodes-langchain.toolsearxng.md)

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

* API URL

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [SearXNG 文档](https://docs.searxng.org/index.html)。

## 使用 API URL <a href="#using-api-url" id="using-api-url"></a>

配置此凭据需要一个正在运行的 SearXNG 实例，且其 URL 必须可从 n8n 访问：

- **API URL**：要连接的 SearXNG 实例的 URL。

运行该服务的更多信息，请参阅 [SearXNG 管理员文档](https://docs.searxng.org/admin/index.html)。
