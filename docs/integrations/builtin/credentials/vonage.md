# Vonage 凭据 <a href="#vonage-credentials" id="vonage-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Vonage](../app-nodes/n8n-nodes-base.vonage.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Vonage 开发者](https://developer.vonage.com)账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Vonage SMS API 文档](https://developer.vonage.com/en/api/sms)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**
- 一个 **API Secret（API 密钥）**

在[开发者控制台](https://dashboard.nexmo.com/)的 **user account > Settings > API Settings（用户账号 > 设置 > API 设置）** 中获取 **API Key（API 密钥）** 和 **API Secret（API 密钥机密值）**。更多信息请参阅[获取账号信息](https://developer.vonage.com/en/account/guides/dashboard-management#retrieve-your-account-information)。
