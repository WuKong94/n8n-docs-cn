# Imperva WAF 凭据 <a href="#imperva-waf-credentials" id="imperva-waf-credentials"></a>

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/credentials/cred-only-statement.md" %}

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Imperva WAF](https://www.imperva.com/products/web-application-firewall-waf/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Imperva WAF 文档](https://docs.imperva.com/bundle/api-docs/page/api/authentication.htm)。

此节点仅提供凭据。更多信息请参阅[自定义 API 操作](../custom-api-actions-for-existing-nodes.md)，也可以在 n8n 网站查看[示例工作流和相关内容](https://n8n.io/integrations/imperva-waf/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API ID**
- 一个 **API Key（API 密钥）**

生成和查看 API 密钥及 ID 的方法，请参阅 [Imperva WAF API 密钥管理文档](https://docs.imperva.com/bundle/cloud-application-security/page/settings/api-keys.htm)。
