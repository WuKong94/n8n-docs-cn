# Mocean 凭据 <a href="#mocean-credentials" id="mocean-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Mocean](../app-nodes/n8n-nodes-base.mocean.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Mocean](https://moceanapi.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Mocean API 文档](https://moceanapi.com/docs/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**
- 一个 **API Secret（API 密钥）**

密钥和机密值均可在 Mocean [控制台](https://dashboard.moceanapi.com/)查看。更多信息请参阅 [API 身份验证](https://moceanapi.com/docs/#authentication)。
