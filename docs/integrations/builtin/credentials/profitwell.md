# ProfitWell 凭据 <a href="#profitwell-credentials" id="profitwell-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [ProfitWell](../app-nodes/n8n-nodes-base.profitwell.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [ProfitWell](https://www2.profitwell.com/signup/start) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API token（API 令牌）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Profitwell API 文档](https://profitwellapiv2.docs.apiary.io/)。

## 使用 API 令牌 <a href="#using-api-token" id="using-api-token"></a>

配置此凭据需要：

- 一个 **API Token（API 令牌）**：进入 **Account Settings > Integrations（账号设置 > 集成）**，选择 **ProfitWell API**，即可获取 API 密钥或令牌。
