# Hunter 凭据 <a href="#hunter-credentials" id="hunter-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Hunter](../app-nodes/n8n-nodes-base.hunter.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Hunter](https://www.hunter.io/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Hunter API 文档](https://hunter.io/api-documentation/v2)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：在[控制台](https://hunter.io/api-keys)中的个人资料页面生成 API 密钥。更多信息请参阅 [Hunter API 身份验证文档](https://hunter.io/api-documentation/v2#authentication)。
