# MessageBird 凭据 <a href="#messagebird-credentials" id="messagebird-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [MessageBird](../app-nodes/n8n-nodes-base.messagebird.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Bird](https://bird.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [MessageBird API 文档](https://docs.bird.com/api)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：在 MessageBird 的 [Access keys（访问密钥）](https://app.bird.com/settings/access-keys) 页面生成相应密钥。详细说明请参阅 [API 授权文档](https://docs.bird.com/api/api-access/api-authorization)。
