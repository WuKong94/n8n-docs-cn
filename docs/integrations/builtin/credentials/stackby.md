# Stackby 凭据 <a href="#stackby-credentials" id="stackby-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Stackby](../app-nodes/n8n-nodes-base.stackby.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Stackby](https://stackby.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Stackby API 文档](https://www.postman.com/lively-equinox-180638/stackby-s-public-workspace/overview)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：进入 [**Account Settings > API（账号设置 > API）**](https://www.stackby.com/account)，创建 API 密钥。更多信息请参阅 [API Key](https://help.stackby.com/en/articles/124-how-to-get-your-api-key-in-stackby)。
