# Affinity 凭据 <a href="#affinity-credentials" id="affinity-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Affinity](../app-nodes/n8n-nodes-base.affinity.md)
- [Affinity Trigger（触发器）](../trigger-nodes/n8n-nodes-base.affinitytrigger.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个订阅 Scale、Advanced 或 Enterprise 档位的 [Affinity](https://www.affinity.co/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关如何使用该服务的更多信息，请参阅 [Affinity API 文档](https://support.affinity.co/s/article/Getting-started-with-the-Affinity-API-FAQs)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：按照[如何获取 Affinity API 密钥文档](https://support.affinity.co/hc/en-us/articles/360032633992-How-to-obtain-your-Affinity-API-key)获取密钥。
