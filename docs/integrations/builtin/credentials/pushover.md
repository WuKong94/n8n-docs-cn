# Pushover 凭据 <a href="#pushover-credentials" id="pushover-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Pushover](../app-nodes/n8n-nodes-base.pushover.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Pushover](https://pushover.net) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务身份验证的更多信息，请参阅 [Pushover API 文档](https://pushover.net/api)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：[注册应用](https://pushover.net/apps/build)时生成。更多信息请参阅[应用注册](https://pushover.net/api#registration)。
