# Humantic AI 凭据 <a href="#humantic-ai-credentials" id="humantic-ai-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Humantic AI](../app-nodes/n8n-nodes-base.humanticai.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Humantic AI](https://humantic.ai/) 账号。

你也可以在 [Humantic AI API](https://api.humantic.ai/) 页面免费试用 API 密钥。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Humantic AI API 文档](https://api.humantic.ai)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：从 [Humantic AI API](https://api.humantic.ai/) 页面获取。
