# Rapid7 InsightVM 凭据 <a href="#rapid7-insightvm-credentials" id="rapid7-insightvm-credentials"></a>

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/credentials/cred-only-statement.md" %}

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Rapid7 InsightVM](https://www.rapid7.com/products/insightvm/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

* API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Rapid7 InsightVM API 文档](https://help.rapid7.com/insightvm/en-us/api/integrations.html)。

此节点仅提供凭据。更多信息请参阅[自定义 API 操作](../custom-api-actions-for-existing-nodes.md)，也可以在 n8n 网站查看[示例工作流和相关内容](https://n8n.io/integrations/rapid7-insight-platform/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要一个 [Rapid7 InsightVM](https://www.rapid7.com/products/insightvm/) 账号，以及：

* **URL**：所请求资源或数据所在的 API 端点 URL。预期格式的更多信息，请参阅 [Rapid7 API 概述的端点部分](https://docs.rapid7.com/insight/api-overview/#endpoint)。
* **API Key**（API 密钥）：请参阅 [Rapid7 平台 API 密钥管理文档](https://docs.rapid7.com/insight/managing-platform-api-keys/)创建 API 密钥。

有关该服务身份验证的更多信息，请参阅 [Rapid7 InsightVM API 文档](https://help.rapid7.com/insightvm/en-us/api/integrations.html)。
