# PhantomBuster 凭据 <a href="#phantombuster-credentials" id="phantombuster-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [PhantomBuster](../app-nodes/n8n-nodes-base.phantombuster.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [PhantomBuster](https://www.phantombuster.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [PhantomBuster API 文档](https://hub.phantombuster.com/reference)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：进入 [**Workspace settings（工作区设置）**](https://phantombuster.com/workspace-settings) **> Third party API keys（第三方 API 密钥）**，选择 **+ Add API Key（添加 API 密钥）**。更多信息请参阅[如何找到 API 密钥](https://hub.phantombuster.com/docs/api#how-to-find-my-api-key)。
