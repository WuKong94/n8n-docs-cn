# UpLead 凭据 <a href="#uplead-credentials" id="uplead-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [UpLead](../app-nodes/n8n-nodes-base.uplead.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [UpLead](https://uplead.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [UpLead API 文档](https://docs.uplead.com/#overview)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：进入 **Account > Profiles（账号 > 个人资料）**，选择 **Generate New API Key（生成新 API 密钥）**。
