# S3 凭据 <a href="#s3-credentials" id="s3-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [S3](../app-nodes/n8n-nodes-base.s3.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

在兼容 S3 的服务器上创建账户。对于通用或非 AWS 的 S3 服务，可使用 S3 节点，例如：

* [DigitalOcean Spaces](https://www.digitalocean.com/products/spaces)
* [MinIO](https://min.io/)
* [Tigris](https://www.tigrisdata.com/)
* [Wasabi](https://wasabi.com/)

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- S3 endpoint（端点）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

这些服务的更多信息，请参阅兼容 S3 的服务提供商文档，例如 [Wasabi REST API 文档](https://docs.wasabi.com/docs/rest-api-introduction)或 [DigitalOcean Spaces API 参考文档](https://docs.digitalocean.com/reference/api/spaces-api/)。

## 使用 S3 端点 <a href="#using-s3-endpoint" id="using-s3-endpoint"></a>

配置此凭据需要：

- **S3 Endpoint**（S3 端点）：输入 S3 存储后端的 URL 端点。
- **Region**（区域）：输入 S3 存储所在区域，部分提供商称其为“region slug”（区域标识）。
- **Access Key ID**（访问密钥 ID）：输入 S3 提供商用于访问存储桶或空间的 S3 访问密钥，部分提供商称其为 API 密钥。
- **Secret Access Key**（秘密访问密钥）：输入 **Access Key ID**（访问密钥 ID）对应的秘密访问密钥。
- **Force Path Style**（强制路径风格）：开启时，连接使用存储桶的路径风格寻址。
- **Ignore SSL Issues**（忽略 SSL 问题）：开启后，即使 SSL 证书验证失败，n8n 仍会连接。

下文提供 DigitalOcean Spaces、Tigris 和 Wasabi 的详细说明。使用其他提供商时，请参阅其文档。

### 使用 DigitalOcean Spaces <a href="#using-digitalocean-spaces" id="using-digitalocean-spaces"></a>

配置此凭据用于 DigitalOcean Spaces 的步骤如下：

1. 在 DigitalOcean 中，打开控制面板的 **Settings**（设置），其中应列出端点。在端点前添加 `https://`，填入 n8n 的 **S3 Endpoint**（S3 端点）。
    - DigitalOcean 端点取决于存储桶所在的数据中心区域。
2. 在 **Region**（区域）中输入存储桶所在区域，例如 `nyc3`。
    - 如果计划使用此凭据创建新 Spaces，请改为输入 `us-east-1`。
3. 从 DigitalOcean 控制面板打开 [**API**](https://cloud.digitalocean.com/account/api/spaces)。
4. 打开 **Spaces Keys**（Spaces 密钥）选项卡。
5. 选择 **Generate New Key**（生成新密钥）。
6. 输入密钥的 **Name**（名称），例如 `n8n integration`，再选择勾选标记。
7. 复制名称旁显示的 **Key**（密钥），填入 n8n 的 **Access Key ID**（访问密钥 ID）。
8. 复制 **Secret**（秘密值），填入 n8n 的 **Secret Access Key**（秘密访问密钥）。
    - 生成密钥和秘密值的更多信息，请参阅[使用访问密钥共享存储桶访问权限](https://docs.digitalocean.com/products/spaces/how-to/manage-access/#access-keys)。
9. 使用子域名或虚拟主机风格寻址时，请保持 **Force Path Style**（强制路径风格）关闭；需要路径风格寻址时再开启。
10. 决定 n8n 凭据如何处理 SSL：
    - 如需遵循 SSL 证书验证，请保持 **Ignore SSL Issues**（忽略 SSL 问题）默认关闭。
    - 如需在 SSL 证书验证失败时仍连接，请开启 **Ignore SSL Issues**（忽略 SSL 问题）。

更多信息，请参阅 DigitalOcean 的 [Spaces API 参考文档](https://docs.digitalocean.com/reference/api/spaces-api/)。

### 使用 Tigris <a href="#using-tigris" id="using-tigris"></a>

配置此凭据用于 Tigris 的步骤如下：

1. 在 **S3 Endpoint**（S3 端点）中输入 `https://t3.storage.dev`。
    - Tigris 使用单一全球端点，无需选择区域，数据从距离请求最近的区域提供。
2. 在 **Region**（区域）中输入 `auto`。
    - 此值是 SigV4 请求签名的必填项，但 Tigris 服务会忽略它。
3. 登录 [Tigris 控制台](https://console.storage.dev/)。
4. 从侧边栏选择 **Access Keys**（访问密钥）。
5. 在右上角选择 **Create New Access Key**（创建新访问密钥）。
6. 输入密钥的 **Name**（名称），例如 `n8n integration`，再选择 **Create**（创建）。
7. 复制显示的 **Access Key ID**（访问密钥 ID，前缀为 `tid_`），填入 n8n 的 **Access Key ID**。
8. 复制显示的 **Secret Access Key**（秘密访问密钥，前缀为 `tsec_`），填入 n8n 的 **Secret Access Key**。
    - 秘密值仅显示一次，丢失后需要创建新密钥。
9. 保持 **Force Path Style**（强制路径风格）关闭，Tigris 使用虚拟主机风格寻址。
10. 决定 n8n 凭据如何处理 SSL：
    - 如需遵循 SSL 证书验证，请保持 **Ignore SSL Issues**（忽略 SSL 问题）默认关闭。
    - 如需在 SSL 证书验证失败时仍连接，请开启 **Ignore SSL Issues**（忽略 SSL 问题）。

更多信息，请参阅 Tigris 的[管理访问密钥文档](https://www.tigrisdata.com/docs/iam/manage-access-key/)。

### 使用 Wasabi <a href="#using-wasabi" id="using-wasabi"></a>

配置此凭据用于 Wasabi 的步骤如下：

1. 在 **S3 Endpoint**（S3 端点）中输入存储桶区域的服务 URL，以 `https://` 开头。
    - 如何确定正确 URL，请参阅 [Wasabi 存储区域的服务 URL](https://docs.wasabi.com/v1/docs/service-urls-for-wasabis-storage-regions)。
2. 在 **Region**（区域）中输入服务 URL 中的区域标识。例如，**S3 Endpoint**（S3 端点）为 `https://s3.us-east-2.wasabisys.com` 时，区域为 `us-east-2`。
3. 以 root 用户身份登录 Wasabi 控制台。
4. 打开 **Menu**（菜单），选择 **Access Keys**（访问密钥）。
5. 选择 **CREATE NEW ACCESS KEY**（创建新访问密钥）。
6. 选择该密钥用于 **Root User**（root 用户）还是 **Sub-User**（子用户），再选择 **CREATE**（创建）。
7. 复制 **Access Key**（访问密钥），填入 n8n 的 **Access Key ID**（访问密钥 ID）。
8. 复制 **Secret Key**（秘密密钥），填入 n8n 的 **Secret Access Key**（秘密访问密钥）。
    - 生成密钥和秘密值的更多信息，请参阅[创建新访问密钥](https://docs.wasabi.com/v1/docs/creating-a-new-access-key)。
9. Wasabi 建议开启 **Force Path Style**（强制路径风格），因为路径风格为存储桶命名提供最大灵活性，可避免域名问题。请参阅 Wasabi 的 [REST API 简介](https://docs.wasabi.com/docs/rest-api-introduction)。
10. 决定 n8n 凭据如何处理 SSL：
    - 如需遵循 SSL 证书验证，请保持 **Ignore SSL Issues**（忽略 SSL 问题）默认关闭。
    - 如需在 SSL 证书验证失败时仍连接，请开启 **Ignore SSL Issues**（忽略 SSL 问题）。

## 其他兼容 S3 的服务提供商 <a id="other-s3-compatible-providers"></a>

其他兼容 S3 的提供商可能发布了此凭据的配置说明：

* [Neon Object Storage](https://neon.com/docs/storage/authentication)：请开启 **Force Path Style**（强制路径风格），因为 Neon 仅支持路径风格寻址。关闭时，节点会因 SSL 问题报错，且 **Ignore SSL Issues**（忽略 SSL 问题）无法解决。
