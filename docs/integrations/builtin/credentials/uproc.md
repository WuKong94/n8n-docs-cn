# uProc 凭据 <a href="#uproc-credentials" id="uproc-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [uProc](../app-nodes/n8n-nodes-base.uproc.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [uProc](https://uproc.io) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [uProc API 文档](https://docs.uproc.io/api/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **Email（电子邮件）** 地址：输入用于登录 uProc 的邮箱地址，也可以在 **Settings > Integrations > API Credentials（设置 > 集成 > API 凭据）** 中查看。
- 一个 **API Key（API 密钥）**：进入 **Settings > Integrations > API Credentials（设置 > 集成 > API 凭据）**，从 **API Credentials** 部分复制 **API Key (real)**，填入 n8n 凭据。
