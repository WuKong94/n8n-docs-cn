# SolarWinds IPAM 凭据 <a href="#solarwinds-ipam-credentials" id="solarwinds-ipam-credentials"></a>

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/credentials/cred-only-statement.md" %}

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

* Username & Password（用户名与密码）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [SolarWinds IPAM API 文档](https://github.com/solarwinds/OrionSDK/wiki/REST)。

## 使用用户名与密码 <a href="#using-username-and-password" id="using-username-and-password"></a>

配置此凭据需要一个 SolarWinds IPAM 账户，以及：

- **URL**：SolarWinds IPAM 服务器的基础 URL。
- **Username**（用户名）：访问 SolarWinds IPAM 所用的用户名。
- **Password**（密码）：访问 SolarWinds IPAM 所用的密码。

有关该服务身份验证的更多信息，请参阅 [SolarWinds IPAM API 文档](https://github.com/solarwinds/OrionSDK/wiki/REST)。
