# Perplexity 凭据 <a href="#perplexity-credentials" id="perplexity-credentials"></a>

这些凭据可用于以下节点的身份验证：

* [Perplexity](../app-nodes/n8n-nodes-langchain.perplexity.md)

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

* API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Perplexity API 文档](https://docs.perplexity.ai/api-reference/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要一个 [Perplexity 账号](https://www.perplexity.ai/account)，以及：

- **一个 Perplexity API 密钥**：创建方法请参阅 [Perplexity API 入门指南](https://docs.perplexity.ai/guides/getting-started)。

有关该服务身份验证的更多信息，请参阅 [Perplexity API 文档](https://docs.perplexity.ai/)。
