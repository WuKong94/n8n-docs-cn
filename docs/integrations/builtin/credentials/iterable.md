# Iterable 凭据 <a href="#iterable-credentials" id="iterable-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Iterable](../app-nodes/n8n-nodes-base.iterable.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Iterable](https://iterable.com) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

该服务的更多信息，请参阅 Iterable API 文档：

- [位于美国的 Iterable 项目](https://api.iterable.com/api/docs)
- [位于欧洲的 Iterable 项目](https://api.eu.iterable.com/api/docs)

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- **API Key**（API 密钥）：创建步骤请参阅 [Iterable 的 Creating API keys 文档](https://support.iterable.com/hc/en-us/articles/360043464871-API-Keys#creating-api-keys)。
