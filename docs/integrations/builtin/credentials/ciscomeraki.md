# Cisco Meraki 凭据 <a href="#cisco-meraki-credentials" id="cisco-meraki-credentials"></a>

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/credentials/cred-only-statement.md" %}

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

- 创建一个 [Cisco DevNet 开发者账号](https://developer.cisco.com)。
- 拥有一个可访问的 [Cisco Meraki 账号](https://meraki.cisco.com/)。

## 身份验证方式 <a href="#authentication-methods" id="authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Cisco Meraki API 文档](https://developer.cisco.com/meraki/api-v1/introduction/)。

此节点仅提供凭据。更多信息请参阅[自定义 API 操作](../custom-api-actions-for-existing-nodes.md)，也可以在 n8n 网站查看[示例工作流和相关内容](https://n8n.io/integrations/cisco-meraki/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：获取方法请参阅 [Cisco Meraki 的获取 Meraki API 密钥文档](https://developer.cisco.com/meraki/api-v1/authorization/#obtaining-your-meraki-api-key)。
