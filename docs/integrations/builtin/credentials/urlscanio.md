# urlscan.io 凭据 <a href="#urlscanio-credentials" id="urlscanio-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [urlscan.io](../app-nodes/n8n-nodes-base.urlscanio.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [urlscan.io](https://urlscan.io/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [urlscan.io API 文档](https://urlscan.io/docs/api/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：在 **Settings & API > API Keys（设置与 API > API 密钥）** 中获取。
