# Copper 凭据 <a href="#copper-credentials" id="copper-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Copper](../app-nodes/n8n-nodes-base.copper.md)
- [Copper Trigger（触发器）](../trigger-nodes/n8n-nodes-base.coppertrigger.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个订阅 **Professional（专业版）** 或 **Business（商业版）** 套餐的 [Copper](https://www.copper.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Copper API 文档](https://developer.copper.com/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：生成方法请参阅 [Copper 的生成 API 密钥文档](https://support.copper.com/en/articles/8823347-generating-an-api-key)。
- 一个 **Email（电子邮件）** 地址：使用 API 密钥创建者的邮箱地址
