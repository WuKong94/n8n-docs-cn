# One Simple API 凭据 <a href="#one-simple-api-credentials" id="one-simple-api-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [One Simple API](../app-nodes/n8n-nodes-base.onesimpleapi.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [One Simple API](https://onesimpleapi.com/register) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API token（API 令牌）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [One Simple API 文档](https://onesimpleapi.com/docs)。

## 使用 API 令牌 <a href="#using-api-token" id="using-api-token"></a>

配置此凭据需要：

- 一个 **API token（API 令牌）**：在 [API Tokens（API 令牌）](https://onesimpleapi.com/user/api-tokens) 页面创建新令牌，并为其选择适当权限。

你也可以通过 **Profile > API Tokens（个人资料 > API 令牌）** 进入 API Tokens 页面。
