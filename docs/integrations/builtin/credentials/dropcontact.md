# Dropcontact 凭据 <a href="#dropcontact-credentials" id="dropcontact-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Dropcontact](../app-nodes/n8n-nodes-base.dropcontact.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

在 [Dropcontact](https://app.dropcontact.com/signup) 中创建开发者账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Dropcontact API 文档](https://developer.dropcontact.com/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：进入 Dropcontact 的 [**API**](https://app.dropcontact.com/api) 页面查看密钥。更多信息请参阅 [Dropcontact API 密钥文档](https://support.dropcontact.com/article/237-how-to-use-the-dropcontact-api-key)。
