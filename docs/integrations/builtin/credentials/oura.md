# Oura 凭据 <a href="#oura-credentials" id="oura-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Oura](../app-nodes/n8n-nodes-base.oura.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Oura](https://ouraring.com/developer) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API access token（API 访问令牌）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Oura API 文档](https://cloud.ouraring.com/v2/docs)。

## 使用 API 访问令牌 <a href="#using-api-access-token" id="using-api-access-token"></a>

配置此凭据需要：

- 一个 **Personal Access Token（个人访问令牌）**：进入 [Personal Access Tokens（个人访问令牌）](https://cloud.ouraring.com/personal-access-tokens) 页面，选择 **Create A New Personal Access Token（创建新的个人访问令牌）**。

更多信息请参阅[如何生成个人访问令牌](https://support.ouraring.com/hc/en-us/articles/4415266939155-The-Oura-API#h_01H5B94SP4P9YHG9ZKN1H69E7Z)。
