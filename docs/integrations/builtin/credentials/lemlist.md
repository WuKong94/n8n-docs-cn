# Lemlist 凭据 <a href="#lemlist-credentials" id="lemlist-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Lemlist](../app-nodes/n8n-nodes-base.lemlist.md)
- [Lemlist Trigger（触发器）](../trigger-nodes/n8n-nodes-base.lemlisttrigger.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

在 [Lemlist](https://www.lemlist.com/) 实例上创建账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Lemlist API 文档](https://developer.lemlist.com/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：在 **Settings > Integrations（设置 > 集成）** 中查看密钥。更多信息请参阅 [API 身份验证文档](https://developer.lemlist.com/#authentication)。
