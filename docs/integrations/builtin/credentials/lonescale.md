# LoneScale 凭据 <a href="#lonescale-credentials" id="lonescale-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [LoneScale](../app-nodes/n8n-nodes-base.lonescale.md)
- [LoneScale Trigger（触发器）](../trigger-nodes/n8n-nodes-base.lonescaletrigger.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [LoneScale](https://www.lonescale.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [LoneScale API 文档](https://docs.lonescale.com/authentication)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：按照 [LoneScale 的生成 API 密钥文档](https://help-center.lonescale.com/en/articles/6454360-lonescale-public-api)生成密钥。
