# Emelia 凭据 <a href="#emelia-credentials" id="emelia-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Emelia](../app-nodes/n8n-nodes-base.emelia.md)
- [Emelia Trigger（触发器）](../trigger-nodes/n8n-nodes-base.emeliatrigger.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Emelia](https://emelia.io) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Emelia API 文档](https://docs.emelia.io/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：在 Emelia 中，选择右上角头像，进入 **Settings（设置）** 中的 **API Keys（API 密钥）**，即可生成密钥。更多信息请参阅 [Emelia API 文档](https://docs.emelia.io/)的身份验证部分。
