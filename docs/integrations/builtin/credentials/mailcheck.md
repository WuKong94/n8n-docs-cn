# Mailcheck 凭据 <a href="#mailcheck-credentials" id="mailcheck-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Mailcheck](../app-nodes/n8n-nodes-base.mailcheck.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Mailcheck](https://mailcheck.co/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Mailcheck API 文档](https://app.mailcheck.co/docs?from=docs)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：在控制台的 API 部分生成 API 密钥。详细说明请参阅 [Mailcheck 的如何创建 API 密钥文档](https://mailcheck.co/create-api-key)。
