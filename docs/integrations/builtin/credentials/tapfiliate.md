# Tapfiliate 凭据 <a href="#tapfiliate-credentials" id="tapfiliate-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [Tapfiliate](../app-nodes/n8n-nodes-base.tapfiliate.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [Tapfiliate](https://tapfiliate.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [Tapfiliate API 文档](https://tapfiliate.com/docs/rest/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：在 [**Profile Settings（个人资料设置）**](https://app.tapfiliate.com/a/profile/) **> API Key（API 密钥）** 中获取。

更多信息请参阅[如何查找账号 ID 和 API 密钥](https://support.tapfiliate.com/en/articles/12793297-how-to-find-account-id-and-api-key)。
