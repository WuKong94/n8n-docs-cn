# E-goi 凭据 <a href="#e-goi-credentials" id="e-goi-credentials"></a>

这些凭据可用于以下节点的身份验证：

- [E-goi](../app-nodes/n8n-nodes-base.egoi.md)

## 前置条件 <a href="#prerequisites" id="prerequisites"></a>

创建一个 [E-goi](https://www.e-goi.com/) 账号。

## 支持的身份验证方式 <a href="#supported-authentication-methods" id="supported-authentication-methods"></a>

- API key（API 密钥）

## 相关资源 <a href="#related-resources" id="related-resources"></a>

有关该服务的更多信息，请参阅 [E-goi API 文档](https://developers.e-goi.com/api/v3/)。

## 使用 API 密钥 <a href="#using-api-key" id="using-api-key"></a>

配置此凭据需要：

- 一个 **API Key（API 密钥）**：生成和查看 API 密钥的方法，请参阅 [E-goi API 密钥文档](https://helpdesk.e-goi.com/511369-Whats-E-gois-API-and-where-do-I-find-my-API-key)。
