# FileMaker 节点 <a href="#filemaker-node" id="filemaker-node"></a>

使用 FileMaker 节点自动处理 FileMaker 中的工作，并将其与其他应用集成。n8n 内置支持多种 FileMaker 功能，包括创建、查找、获取、编辑和复制记录。

本页列出了 FileMaker 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [FileMaker 凭据](../credentials/filemaker.md)。
{% endhint %}

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/app-nodes/ai-tools.md" %}

## 操作 <a href="#operations" id="operations"></a>

- Find Records（查找记录）
- Get Records（获取记录）
- Get Records by Id（按 ID 获取记录）
- Perform Script（执行脚本）
- Create Record（创建记录）
- Edit Record（编辑记录）
- Duplicate Record（复制记录）
- Delete Record（删除记录）
