# LoneScale 节点 <a href="#lonescale-node" id="lonescale-node"></a>

使用 LoneScale 节点自动处理 LoneScale 中的工作，并将其与其他应用集成。n8n 内置支持管理 LoneScale 中的列表和数据项。

本页列出了 LoneScale 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

该节点的身份验证信息，请参阅 [LoneScale 凭据文档](../credentials/lonescale.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* List（列出）
	* Create（创建）
* Item（数据项）
	* Create（创建）
