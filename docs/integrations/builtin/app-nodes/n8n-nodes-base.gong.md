# Gong 节点 <a href="#gong-node" id="gong-node"></a>

使用 Gong 节点自动处理 Gong 中的工作，并将其与其他应用集成。n8n 内置支持多种 Gong 功能，包括获取一个或多个通话和用户。

本页列出了 Gong 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

该节点的身份验证信息，请参阅 [Gong 凭据文档](../credentials/gong.md)。
{% endhint %}


## 操作 <a href="#operations" id="operations"></a>


* Call（通话）
	* Get（获取）
	* Get Many（获取多条）
* User（用户）
	* Get（获取）
	* Get Many（获取多条）
