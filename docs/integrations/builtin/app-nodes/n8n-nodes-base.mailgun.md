# Mailgun 节点 <a href="#mailgun-node" id="mailgun-node"></a>

使用 Mailgun 节点自动处理 Mailgun 中的工作，并将其与其他应用集成。n8n 内置支持通过 Mailgun 发送电子邮件。

本页列出了 Mailgun 节点支持的操作，并提供更多资源的链接。
