# WooCommerce 节点 <a href="#woocommerce-node" id="woocommerce-node"></a>

使用 WooCommerce 节点自动处理 WooCommerce 中的工作，并将其与其他应用集成。n8n 内置支持多种 WooCommerce 功能，包括创建和删除客户、订单和产品。

本页列出了 WooCommerce 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [WooCommerce 凭据](../credentials/woocommerce.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Customer（客户）
    * Create a customer（创建客户）
    * Delete a customer（删除客户）
    * Retrieve a customer（获取客户）
    * Retrieve all customers（获取全部客户）
    * Update a customer（更新客户）
* Order（订单）
    * Create a order（创建订单）
    * Delete a order（删除订单）
    * Get a order（获取订单）
    * Get all orders（获取全部订单）
    * Update an order（更新订单）
* Product（产品）
    * Create a product（创建产品）
    * Delete a product（删除产品）
    * Get a product（获取产品）
    * Get all products（获取全部产品）
    * Update a product（更新产品）
