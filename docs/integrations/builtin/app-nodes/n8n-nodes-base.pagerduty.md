# PagerDuty 节点 <a href="#pagerduty-node" id="pagerduty-node"></a>

使用 PagerDuty 节点自动处理 PagerDuty 中的工作，并将其与其他应用集成。n8n 内置支持多种 PagerDuty 功能，包括创建事件备注，以及更新和获取全部日志条目与用户。

本页列出了 PagerDuty 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [PagerDuty 凭据](../credentials/pagerduty.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Incident（事件）
    * Create an incident（创建事件）
    * Get an incident（获取事件）
    * Get all incidents（获取全部事件）
    * Update an incident（更新事件）
* Incident Note（事件备注）
    * Create an incident note（创建事件备注）
    * Get all incident's notes（获取事件的全部备注）
* Log Entry（日志条目）
    * Get a log entry（获取日志条目）
    * Get all log entries（获取全部日志条目）
* User（用户）
    * Get a user（获取用户）
