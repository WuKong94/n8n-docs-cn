# Action Network 节点 <a href="#action-network-node" id="action-network-node"></a>

使用 Action Network 节点自动处理 Action Network 中的工作，并将其与其他应用集成。n8n 内置支持多种 Action Network 功能，包括创建、更新和删除事件、人员、标签和签名。

本页列出了 Action Network 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Action Network 凭据](../credentials/actionnetwork.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Attendance（出席记录）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
* Event（事件）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
* Person（人员）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Person Tag（人员标签）
    * Add（添加）
    * Remove（移除）
* Petition（请愿）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Signature（签名）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Tag（标签）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
