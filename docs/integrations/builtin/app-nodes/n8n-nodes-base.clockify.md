# Clockify 节点 <a href="#clockify-node" id="clockify-node"></a>

使用 Clockify 节点自动处理 Clockify 中的工作，并将其与其他应用集成。n8n 内置支持多种 Clockify 功能，包括创建、更新、获取和删除任务、工时条目、项目和标签。

本页列出了 Clockify 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Clockify 凭据](../credentials/clockify.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Project（项目）
    * Create a project（创建项目）
    * Delete a project（删除项目）
    * Get a project（获取项目）
    * Get all projects（获取全部项目）
    * Update a project（更新项目）
* Tag（标签）
    * Create a tag（创建标签）
    * Delete a tag（删除标签）
    * Get all tags（获取全部标签）
    * Update a tag（更新标签）
* Task（任务）
    * Create a task（创建任务）
    * Delete a task（删除任务）
    * Get a task（获取任务）
    * Get all tasks（获取全部任务）
    * Update a task（更新任务）
* Time Entry（工时条目）
    * Create a time entry（创建工时条目）
    * Delete a time entry（删除工时条目）
    * Get time entry（获取工时条目）
    * Update a time entry（更新工时条目）
