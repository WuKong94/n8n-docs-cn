# Customer.io 节点 <a href="#customerio-node" id="customerio-node"></a>

使用 Customer.io 节点自动处理 Customer.io 中的工作，并将其与其他应用集成。n8n 内置支持多种 Customer.io 功能，包括创建和更新客户、跟踪事件和获取营销活动。

本页列出了 Customer.io 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Customer.io 凭据](../credentials/customerio.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Customer（客户）
    * Create/Update a customer.（创建或更新客户）
    * Delete a customer.（删除客户）
* Event（事件）
    * Track a customer event.（跟踪客户事件）
    * Track an anonymous event.（跟踪匿名事件）
* Campaign（营销活动）
    * Get（获取）
    * Get All（获取全部）
    * Get Metrics（获取指标）
* Segment（细分群组）
    * Add Customer（添加客户）
    * Remove Customer（移除客户）
