# Medium 节点 <a href="#medium-node" id="medium-node"></a>

使用 Medium 节点自动处理 Medium 中的工作，并将其与其他应用集成。n8n 内置支持多种 Medium 功能，包括创建文章和获取出版物。

本页列出了 Medium 节点支持的操作，并提供更多资源的链接。

{% hint style="warning" %}
**Medium API 已停止支持**

Medium 已停止支持其 API。Medium 节点仍会显示在 n8n 中，但无法再配置新的 API 密钥进行身份验证。

如何设置已有 API 密钥，请参阅 [Medium 凭据](../credentials/medium.md)。
{% endhint %}
