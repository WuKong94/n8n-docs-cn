# Xero 节点 <a href="#xero-node" id="xero-node"></a>

使用 Xero 节点自动处理 Xero 中的工作，并将其与其他应用集成。n8n 内置支持多种 Xero 功能，包括创建、更新和获取联系人及发票。

本页列出了 Xero 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Xero 凭据](../credentials/xero.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Contact（联系人）
    * Create a contact（创建联系人）
    * Get a contact（获取联系人）
    * Get all contacts（获取全部联系人）
    * Update a contact（更新联系人）
* Invoice（发票）
    * Create a invoice（创建发票）
    * Get a invoice（获取发票）
    * Get all invoices（获取全部发票）
    * Update a invoice（更新发票）
