# QuickBooks Online 节点 <a href="#quickbooks-online-node" id="quickbooks-online-node"></a>

使用 QuickBooks 节点自动处理 QuickBooks 中的工作，并将其与其他应用集成。n8n 内置支持多种 QuickBooks 功能，包括创建、更新、删除和获取账单、客户、员工、估价单及发票。

本页列出了 QuickBooks 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

身份验证设置说明，请参阅 [QuickBooks 凭据](../credentials/quickbooks.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Bill（账单）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Customer（客户）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Employee（员工）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Estimate（估价单）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Send（发送）
    * Update（更新）
* Invoice（发票）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Send（发送）
    * Update（更新）
    * Void（作废）
* Item（数据项）
    * Get（获取）
    * Get All（获取全部）
* Payment（付款）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Send（发送）
    * Update（更新）
    * Void（作废）
* Purchase（采购）
    * Get（获取）
    * Get All（获取全部）
* Transaction（交易）
    * Get Report（获取报告）
* Vendor（供应商）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
