# Magento 2 节点 <a href="#magento-2-node" id="magento-2-node"></a>

使用 Magento 2 节点自动处理 Magento 2 中的工作，并将其与其他应用集成。n8n 内置支持多种 Magento 2 功能，包括创建、更新、删除和获取客户、发票、订单和产品。

本页列出了 Magento 2 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Magento 2 凭据](../credentials/magento2.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Customer（客户）
    * Create a new customer（创建新客户）
    * Delete a customer（删除客户）
    * Get a customer（获取客户）
    * Get all customers（获取全部客户）
    * Update a customer（更新客户）
* Invoice（发票）
    * Create an invoice（创建发票）
* Order（订单）
    * Cancel an order（取消订单）
    * Get an order（获取订单）
    * Get all orders（获取全部订单）
    * Ship an order（为订单发货）
* Product（产品）
    * Create a product（创建产品）
    * Delete a product（删除产品）
    * Get a product（获取产品）
    * Get all products（获取全部产品）
    * Update a product（更新产品）
