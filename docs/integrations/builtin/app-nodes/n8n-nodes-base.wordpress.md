# WordPress 节点 <a href="#wordpress-node" id="wordpress-node"></a>

使用 WordPress 节点自动处理 WordPress 中的工作，并将其与其他应用集成。n8n 内置支持多种 WordPress 功能，包括创建、更新和获取文章及用户。

本页列出了 WordPress 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [WordPress 凭据](../credentials/wordpress.md)。
{% endhint %}

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/app-nodes/ai-tools.md" %}

## 操作 <a href="#operations" id="operations"></a>

* Post（帖子）
    * Create a post（创建帖子）
    * Get a post（获取帖子）
    * Get all posts（获取全部帖子）
    * Update a post（更新帖子）
* Pages（页面）
    * Create a page（创建页面）
    * Get a page（获取页面）
    * Get all pages（获取全部页面）
    * Update a page（更新页面）
* User（用户）
    * Create a user（创建用户）
    * Get a user（获取用户）
    * Get all users（获取全部用户）
    * Update a user（更新用户）
