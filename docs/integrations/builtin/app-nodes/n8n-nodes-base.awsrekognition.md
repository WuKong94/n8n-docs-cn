# AWS Rekognition 节点 <a href="#aws-rekognition-node" id="aws-rekognition-node"></a>

使用 AWS Rekognition 节点自动处理 AWS Rekognition 中的工作，并将其与其他应用集成。n8n 内置支持多种 AWS Rekognition 功能，包括分析图像。

本页列出了 AWS Rekognition 节点支持的操作，并提供更多资源的链接。

有关身份验证设置，请参阅 [AWS Rekognition 凭据](../credentials/aws.md)。
