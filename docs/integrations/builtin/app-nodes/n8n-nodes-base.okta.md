# Okta 节点 <a href="#okta-node" id="okta-node"></a>

使用 Okta 节点自动处理 Okta 中的工作，并将其与其他应用集成。n8n 内置支持多种 Okta 功能，包括创建、更新和删除用户。

本页列出了 Okta 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

该节点的身份验证信息，请参阅 [Okta 凭据文档](../credentials/okta.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

- User（用户）
    - Create a new user（创建新用户）
    - Delete an existing user（删除现有用户）
    - Get details of a user（获取用户详情）
    - Get many users（获取多条用户）
    - Update an existing user（更新现有用户）
