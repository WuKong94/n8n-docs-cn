# Perplexity 节点 <a href="#perplexity-node" id="perplexity-node"></a>

使用 Perplexity 节点自动处理 Perplexity 中的工作，并将其与其他应用集成。n8n 内置支持向模型发送消息。

本页列出了 Perplexity 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

该节点的身份验证信息，请参阅 [Perplexity 凭据文档](../credentials/perplexity.md)。
{% endhint %}


## 操作 <a href="#operations" id="operations"></a>

* **Message a Model（向模型发送消息）**：为给定文本生成一个或多个补全结果。
