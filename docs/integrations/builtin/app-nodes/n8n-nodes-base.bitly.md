# Bitly 节点 <a href="#bitly-node" id="bitly-node"></a>

使用 Bitly 节点自动处理 Bitly 中的工作，并将其与其他应用集成。n8n 内置支持多种 Bitly 功能，包括创建、获取和更新链接。

本页列出了 Bitly 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Bitly 凭据](../credentials/bitly.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Link（链接）
    * Create a link（创建链接）
    * Get a link（获取链接）
    * Update a link（更新链接）
