# Tapfiliate 节点 <a href="#tapfiliate-node" id="tapfiliate-node"></a>

使用 Tapfiliate 节点自动处理 Tapfiliate 中的工作，并将其与其他应用集成。n8n 内置支持多种 Tapfiliate 功能，包括创建和删除推广合作伙伴，以及添加合作伙伴元数据。

本页列出了 Tapfiliate 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Tapfiliate 凭据](../credentials/tapfiliate.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Affiliate（推广合作伙伴）
    * Create an affiliate（创建推广合作伙伴）
    * Delete an affiliate（删除推广合作伙伴）
    * Get an affiliate by ID（按 ID 获取推广合作伙伴）
    * Get all affiliates（获取全部推广合作伙伴）
* Affiliate Metadata（推广合作伙伴元数据）
    * Add metadata to affiliate（为推广合作伙伴添加元数据）
    * Remove metadata from affiliate（从推广合作伙伴移除元数据）
    * Update affiliate's metadata（更新推广合作伙伴的元数据）
* Program Affiliate（计划中的推广合作伙伴）
    * Add affiliate to program（将推广合作伙伴添加到计划）
    * Approve an affiliate for a program（批准推广合作伙伴加入计划）
    * Disapprove an affiliate（拒绝推广合作伙伴）
    * Get an affiliate in a program（获取计划中的推广合作伙伴）
    * Get all affiliates in program（获取计划中的全部推广合作伙伴）
