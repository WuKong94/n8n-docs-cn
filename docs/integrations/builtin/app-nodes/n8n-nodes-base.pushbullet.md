# Pushbullet 节点 <a href="#pushbullet-node" id="pushbullet-node"></a>

使用 Pushbullet 节点自动处理 Pushbullet 中的工作，并将其与其他应用集成。n8n 内置支持多种 Pushbullet 功能，包括创建、更新、删除和获取推送。

本页列出了 Pushbullet 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Pushbullet 凭据](../credentials/pushbullet.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Push（推送）
    * Create a push（创建推送）
    * Delete a push（删除推送）
    * Get all pushes（获取全部推送）
    * Update a push（更新推送）
