# DHL 节点 <a href="#dhl-node" id="dhl-node"></a>

使用 DHL 节点自动处理 DHL 中的工作，并将其与其他应用集成。n8n 内置支持多种 DHL 功能，包括跟踪货运。

本页列出了 DHL 节点支持的操作，并提供更多资源的链接。
