# Chargebee 节点 <a href="#chargebee-node" id="chargebee-node"></a>

使用 Chargebee 节点自动处理 Chargebee 中的工作，并将其与其他应用集成。n8n 内置支持多种 Chargebee 功能，包括创建客户、返回发票和取消订阅。

本页列出了 Chargebee 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Chargebee 凭据](../credentials/chargebee.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Customer（客户）
    * Create a customer（创建客户）
* Invoice（发票）
    * Return the invoices（返回发票）
    * Get URL for the invoice PDF（获取发票 PDF 的 URL）
* Subscription（订阅）
    * Cancel a subscription（取消订阅）
    * Delete a subscription（删除订阅）
