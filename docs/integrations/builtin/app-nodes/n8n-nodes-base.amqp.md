# AMQP Sender 节点 <a href="#amqp-sender-node" id="amqp-sender-node"></a>

使用 AMQP Sender 节点自动处理 AMQP Sender 中的工作，并将其与其他应用集成。n8n 内置支持多种 AMQP Sender 功能，包括发送消息。

本页列出了 AMQP Sender 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [AMQP Sender 凭据](../credentials/amqp.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

- Send message（发送消息）
