# DeepL 节点 <a href="#deepl-node" id="deepl-node"></a>

使用 DeepL 节点自动处理 DeepL 中的工作，并将其与其他应用集成。n8n 内置支持多种 DeepL 功能，包括语言翻译。

本页列出了 DeepL 节点支持的操作，并提供更多资源的链接。

有关身份验证设置，请参阅 [DeepL 凭据](../credentials/deepl.md)。
