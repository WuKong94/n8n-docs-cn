# urlscan.io 节点 <a href="#urlscanio-node" id="urlscanio-node"></a>

使用 urlscan.io 节点自动处理 urlscan.io 中的工作，并将其与其他应用集成。n8n 内置支持多种 urlscan.io 功能，包括获取和执行扫描。

本页列出了 urlscan.io 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [urlscan.io 凭据](../credentials/urlscanio.md)。
{% endhint %}

* Scan（扫描）
