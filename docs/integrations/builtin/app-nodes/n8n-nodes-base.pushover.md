# Pushover 节点 <a href="#pushover-node" id="pushover-node"></a>

使用 Pushover 节点自动处理 Pushover 中的工作，并将其与其他应用集成。n8n 支持通过 Pushover 发送推送通知。

本页列出了 Pushover 节点支持的操作，并提供更多资源的链接。
