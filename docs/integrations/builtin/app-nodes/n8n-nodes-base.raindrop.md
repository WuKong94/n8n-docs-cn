# Raindrop 节点 <a href="#raindrop-node" id="raindrop-node"></a>

使用 Raindrop 节点自动处理 Raindrop 中的工作，并将其与其他应用集成。n8n 内置支持多种 Raindrop 功能，包括获取用户、删除标签，以及创建、更新、删除和获取集合与书签。

本页列出了 Raindrop 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Raindrop 凭据](../credentials/raindrop.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Bookmark（书签）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Collection（集合）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Tag（标签）
    * Delete（删除）
    * Get All（获取全部）
* User（用户）
    * Get（获取）
