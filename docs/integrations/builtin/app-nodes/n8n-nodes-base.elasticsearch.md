# Elasticsearch 节点 <a href="#elasticsearch-node" id="elasticsearch-node"></a>

使用 Elasticsearch 节点自动处理 Elasticsearch 中的工作，并将其与其他应用集成。n8n 内置支持多种 Elasticsearch 功能，包括创建、更新、删除和获取文档及索引。

本页列出了 Elasticsearch 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Elasticsearch 凭据](../credentials/elasticsearch.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Document（文档）
    * Create a document（创建文档）
    * Delete a document（删除文档）
    * Get a document（获取文档）
    * Get all documents（获取全部文档）
    * Update a document（更新文档）
* Index（索引）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
