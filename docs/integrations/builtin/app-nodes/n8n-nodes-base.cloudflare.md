# Cloudflare 节点 <a href="#cloudflare-node" id="cloudflare-node"></a>

使用 Cloudflare 节点自动处理 Cloudflare 中的工作，并将其与其他应用集成。n8n 内置支持多种 Cloudflare 功能，包括删除、获取和上传区域证书。

本页列出了 Cloudflare 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Cloudflare 凭据](../credentials/cloudflare.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Zone Certificate（区域证书）
	* Delete（删除）
	* Get（获取）
	* Get Many（获取多条）
	* Upload（上传）
