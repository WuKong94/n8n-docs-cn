# Clearbit 节点 <a href="#clearbit-node" id="clearbit-node"></a>

使用 Clearbit 节点自动处理 Clearbit 中的工作，并将其与其他应用集成。n8n 内置支持多种 Clearbit 功能，包括自动补全和查找公司及人员。

本页列出了 Clearbit 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Clearbit 凭据](../credentials/clearbit.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Company（公司）
    * Auto-complete company names and retrieve logo and domain（自动补全公司名称，并获取标志和域名）
    * Look up person and company data based on an email or domain（根据邮箱或域名查找个人及公司数据）
* Person（人员）
    * Look up a person and company data based on an email or domain（根据邮箱或域名查找个人及公司数据）
