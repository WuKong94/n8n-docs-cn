# Bubble 节点 <a href="#bubble-node" id="bubble-node"></a>

使用 Bubble 节点自动处理 Bubble 中的工作，并将其与其他应用集成。n8n 内置支持多种 Bubble 功能，包括创建、删除、获取和更新对象。

本页列出了 Bubble 节点支持的操作，并提供更多资源的链接。

**凭据**

有关身份验证设置，请参阅 [Bubble 凭据](../credentials/bubble.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Object（对象）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
