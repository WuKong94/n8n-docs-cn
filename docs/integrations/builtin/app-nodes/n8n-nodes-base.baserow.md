# Baserow 节点 <a href="#baserow-node" id="baserow-node"></a>

使用 Baserow 节点自动处理 Baserow 中的工作，并将其与其他应用集成。n8n 内置支持多种 Baserow 功能，包括创建、获取、检索和更新行。

本页列出了 Baserow 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Baserow 凭据](../credentials/baserow.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Row（行）
    * Create multiple rows（批量创建行）
    * Delete multiple rows（批量删除行）
    * Update multiple rows（批量更新行）
    * Create a row（创建行）
    * Delete a row（删除行）
    * Get a row（获取行）
    * Get many rows（获取多条行）
    * Update a row（更新行）
