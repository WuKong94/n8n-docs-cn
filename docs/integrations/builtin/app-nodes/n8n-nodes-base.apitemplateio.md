# APITemplate.io 节点 <a href="#apitemplateio-node" id="apitemplateio-node"></a>

使用 APITemplate.io 节点自动处理 APITemplate.io 中的工作，并将其与其他应用集成。n8n 内置支持多种 APITemplate.io 功能，包括获取和创建账户及 PDF。

本页列出了 APITemplate.io 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [APITemplate.io 凭据](../credentials/apitemplateio.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Account（账户）
    * Get（获取）
* Image（图像）
    * Create（创建）
* PDF（PDF 文档）
    * Create（创建）
