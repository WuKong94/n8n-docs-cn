# Dropbox 节点 <a href="#dropbox-node" id="dropbox-node"></a>

使用 Dropbox 节点自动处理 Dropbox 中的工作，并将其与其他应用集成。n8n 内置支持多种 Dropbox 功能，包括创建、下载、移动和复制文件及文件夹。

本页列出了 Dropbox 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Dropbox 凭据](../credentials/dropbox.md)。
{% endhint %}

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/app-nodes/ai-tools.md" %}

## 操作 <a href="#operations" id="operations"></a>

* File（文件）
    * Copy a file（复制文件）
    * Delete a file（删除文件）
    * Download a file（下载文件）
    * Move a file（移动文件）
    * Upload a file（上传文件）
* Folder（文件夹）
    * Copy a folder（复制文件夹）
    * Create a folder（创建文件夹）
    * Delete a folder（删除文件夹）
    * Return the files and folders in a given folder（返回给定文件夹中的文件和文件夹）
    * Move a folder（移动文件夹）
* Search（搜索）
    * Query（查询）
