# Pushcut 节点 <a href="#pushcut-node" id="pushcut-node"></a>

使用 Pushcut 节点自动处理 Pushcut 中的工作，并将其与其他应用集成。n8n 支持通过 Pushcut 发送通知。

本页列出了 Pushcut 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Pushcut 凭据](../credentials/pushcut.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Notification（通知）
    * Send a notification（发送通知）
