# Plivo 节点 <a href="#plivo-node" id="plivo-node"></a>

使用 Plivo 节点自动处理 Plivo 中的工作，并将其与其他应用集成。n8n 内置支持多种 Plivo 功能，包括拨打电话和发送短信或彩信。

本页列出了 Plivo 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Plivo 凭据](../credentials/plivo.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Call（通话）
    * Make a voice call（拨打语音电话）
* MMS（彩信）
    * Send an MMS message (US/Canada only)（发送彩信，仅限美国和加拿大）
* SMS（短信）
    * Send an SMS message.（发送短信）
