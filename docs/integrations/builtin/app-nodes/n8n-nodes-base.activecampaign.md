# ActiveCampaign 节点 <a href="#activecampaign-node" id="activecampaign-node"></a>

使用 ActiveCampaign 节点自动处理 ActiveCampaign 中的工作，并将其与其他应用集成。n8n 内置支持多种 ActiveCampaign 功能，包括创建、获取、更新和删除账户、联系人、订单、电商客户、连接、列表、标签和商机。

本页列出了 ActiveCampaign 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [ActiveCampaign 凭据](../credentials/activecampaign.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Account（账户）
    * Create an account（创建账户）
    * Delete an account（删除账户）
    * Get data of an account（获取账户数据）
    * Get data of all accounts（获取所有账户数据）
    * Update an account（更新账户）
* Account Contact（账户联系人）
    * Create an association（创建关联）
    * Delete an association（删除关联）
    * Update an association（更新关联）
* Contact（联系人）
    * Create a contact（创建联系人）
    * Delete a contact（删除联系人）
    * Get data of a contact（获取联系人数据）
    * Get data of all contact（获取所有联系人数据）
    * Update a contact（更新联系人）
* Contact List（联系人列表）
    * Add contact to a list（将联系人添加到列表）
    * Remove contact from a list（从列表移除联系人）
* Contact Tag（联系人标签）
    * Add a tag to a contact（为联系人添加标签）
    * Remove a tag from a contact（移除联系人的标签）
* Connection（连接）
    * Create a connection（创建连接）
    * Delete a connection（删除连接）
    * Get data of a connection（获取连接数据）
    * Get data of all connections（获取所有连接数据）
    * Update a connection（更新连接）
* Deal（商机）
    * Create a deal（创建商机）
    * Delete a deal（删除商机）
    * Get data of a deal（获取商机数据）
    * Get data of all deals（获取所有商机数据）
    * Update a deal（更新商机）
    * Create a deal note（创建商机备注）
    * Update a deal note（更新商机备注）
* E-commerce Order（电子商务订单）
    * Create a order（创建订单）
    * Delete a order（删除订单）
    * Get data of a order（获取订单数据）
    * Get data of all orders（获取所有订单数据）
    * Update a order（更新订单）
* E-Commerce Customer（电子商务客户）
    * Create a E-commerce Customer（创建电子商务客户）
    * Delete a E-commerce Customer（删除电子商务客户）
    * Get data of a E-commerce Customer（获取电子商务客户数据）
    * Get data of all E-commerce Customer（获取所有电子商务客户数据）
    * Update a E-commerce Customer（更新电子商务客户）
* E-commerce Order Products（电子商务订单商品）
    * Get data of all order products（获取所有订单商品数据）
    * Get data of a ordered product（获取已订购商品的数据）
    * Get data of an order's products（获取订单中的商品数据）
* List（列出）
    * Get all lists（获取全部列表）
* Tag（标签）
    * Create a tag（创建标签）
    * Delete a tag（删除标签）
    * Get data of a tag（获取标签数据）
    * Get data of all tags（获取所有标签数据）
    * Update a tag（更新标签）
