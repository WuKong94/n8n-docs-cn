# Bitwarden 节点 <a href="#bitwarden-node" id="bitwarden-node"></a>

使用 Bitwarden 节点自动处理 Bitwarden 中的工作，并将其与其他应用集成。n8n 内置支持多种 Bitwarden 功能，包括创建、获取、删除和更新集合、事件、群组和成员。

本页列出了 Bitwarden 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Bitwarden 凭据](../credentials/bitwarden.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Collection（集合）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Event（事件）
    * Get All（获取全部）
* Group（群组）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Get Members（获取成员）
    * Update（更新）
    * Update Members（更新成员）
* Member（成员）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Get Groups（获取群组）
    * Update（更新）
    * Update Groups（更新群组）
