# ServiceNow 节点 <a href="#servicenow-node" id="servicenow-node"></a>

使用 ServiceNow 节点自动处理 ServiceNow 中的工作，并将其与其他应用集成。n8n 内置支持多种 ServiceNow 功能，包括获取业务服务、部门、配置项和字典，以及创建、更新和删除事件、用户与表记录。

本页列出了 ServiceNow 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [ServiceNow 凭据](../credentials/servicenow.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Business Service（业务服务）
    * Get All（获取全部）
* Configuration Items（配置项）
    * Get All（获取全部）
* Department（部门）
    * Get All（获取全部）
* Dictionary（字典）
    * Get All（获取全部）
* Incident（事件）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Table Record（表记录）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* User（用户）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* User Group（用户组）
    * Get All（获取全部）
* User Role（用户角色）
    * Get All（获取全部）
