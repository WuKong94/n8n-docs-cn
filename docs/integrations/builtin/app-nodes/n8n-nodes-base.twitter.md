# X (Formerly Twitter) 节点 <a href="#x-formerly-twitter-node" id="x-formerly-twitter-node"></a>

使用 X 节点自动处理 X 中的工作，并将其与其他应用集成。n8n 内置支持多种 X 功能，包括创建私信，以及删除、搜索、点赞和转发推文。

本页列出了 X 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

身份验证设置说明，请参阅 [X 凭据](../credentials/twitter.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Direct Message（私信）
    * Create a direct message（创建私信）
* Tweet（推文）
    * Create or reply a tweet（创建或回复推文）
    * Delete a tweet（删除推文）
    * Search tweets（搜索推文）
    * Like a tweet（点赞推文）
    * Retweet a tweet（转发推文）
* User（用户）
    * Get a user（获取用户）
* List（列出）
    * Add a member to a list（向列表添加成员）
