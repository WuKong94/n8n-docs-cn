# seven 节点 <a href="#seven-node" id="seven-node"></a>

使用 seven 节点自动处理 seven 中的工作，并将其与其他应用集成。n8n 内置支持多种 seven 功能，包括发送短信和将文本转换为语音。

本页列出了 seven 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [seven 凭据](../credentials/sms77.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* SMS（短信）
    * Send SMS（发送短信）
* Voice Call（语音通话）
    * Converts text to voice and calls a given number（将文本转换为语音并拨打指定号码）
