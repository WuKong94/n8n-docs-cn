# Affinity 节点 <a href="#affinity-node" id="affinity-node"></a>

使用 Affinity 节点自动处理 Affinity 中的工作，并将其与其他应用集成。n8n 内置支持多种 Affinity 功能，包括创建、获取、更新和删除列表、条目、组织和人员。

本页列出了 Affinity 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Affinity 凭据](../credentials/affinity.md)。
{% endhint %}

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/app-nodes/ai-tools.md" %}

## 操作 <a href="#operations" id="operations"></a>

* List（列出）
    * Get a list（获取列表）
    * Get all lists（获取全部列表）
* List Entry（列出条目）
    * Create a list entry（创建列表条目）
    * Delete a list entry（删除列表条目）
    * Get a list entry（获取列表条目）
    * Get all list entries（获取全部列表条目）
* Organization（组织）
    * Create an organization（创建组织）
    * Delete an organization（删除组织）
    * Get an organization（获取组织）
    * Get all organizations（获取全部组织）
    * Update an organization（更新组织）
* Person（人员）
    * Create a person（创建人员）
    * Delete a person（删除人员）
    * Get a person（获取人员）
    * Get all persons（获取全部人员）
    * Update a person（更新人员）
