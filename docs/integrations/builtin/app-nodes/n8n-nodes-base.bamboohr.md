# BambooHR 节点 <a href="#bamboohr-node" id="bamboohr-node"></a>

使用 BambooHR 节点自动处理 BambooHR 中的工作，并将其与其他应用集成。n8n 内置支持多种 BambooHR 功能，包括创建、删除、下载和获取公司报告、员工文档和文件。

本页列出了 BambooHR 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [BambooHR 凭据](../credentials/bamboohr.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Company Report（公司报告）
    * Get a company report（获取公司报告）
* Employee（员工）
    * Create an employee（创建员工）
    * Get an employee（获取员工）
    * Get all employees（获取全部员工）
    * Update an employee（更新员工）
* Employee Document（员工文档）
    * Delete an employee document（删除员工文档）
    * Download an employee document（下载员工文档）
    * Get all employee document（获取全部员工文档）
    * Update an employee document（更新员工文档）
    * Upload an employee document（上传员工文档）
* File（文件）
    * Delete a company file（删除公司文件）
    * Download a company file（下载公司文件）
    * Get all company files（获取全部公司文件）
    * Update a company file（更新公司文件）
    * Upload a company file（上传公司文件）
