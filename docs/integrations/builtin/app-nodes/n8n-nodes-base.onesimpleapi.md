# One Simple API 节点 <a href="#one-simple-api-node" id="one-simple-api-node"></a>

使用 One Simple API 节点自动处理 One Simple API 中的工作，并将其与其他应用集成。n8n 内置支持多种 One Simple API 功能，包括获取个人资料、检索信息和生成实用工具。

本页列出了 One Simple API 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [One Simple API 凭据](../credentials/onesimpleapi.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Information（信息）
    * Convert a value between currencies（在不同货币间换算金额）
    * Retrieve image metadata from a URL（从 URL 获取图片元数据）
* Social Profile（社交资料）
    * Get details about an Instagram profile（获取 Instagram 个人资料的详情）
    * Get details about a Spotify Artist（获取 Spotify 艺人的详情）
* Utility（实用工具）
    * Expand a shortened url（展开短网址）
    * Generate a QR Code（生成二维码）
    * Validate an email address（验证电子邮箱地址）
* Website（网站）
    * Generate a PDF from a webpage（将网页生成 PDF）
    * Get SEO information from website（获取网站 SEO 信息）
    * Create a screenshot from a webpage（创建网页截图）
