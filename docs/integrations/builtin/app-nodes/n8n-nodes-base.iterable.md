# Iterable 节点 <a href="#iterable-node" id="iterable-node"></a>

使用 Iterable 节点自动处理 Iterable 中的工作，并将其与其他应用集成。n8n 内置支持多种 Iterable 功能，包括创建用户、记录用户执行的操作，以及在列表中添加和移除用户。

本页列出了 Iterable 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Iterable 凭据](../credentials/iterable.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Event（事件）
    * Record the actions a user perform（记录用户执行的操作）
* User（用户）
    * Create/Update a user（创建或更新用户）
    * Delete a user（删除用户）
    * Get a user（获取用户）
* User List（用户列表）
    * Add user to list（将用户添加到列表）
    * Remove a user from a list（从列表中移除用户）
