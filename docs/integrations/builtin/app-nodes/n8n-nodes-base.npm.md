# npm 节点 <a href="#npm-node" id="npm-node"></a>

使用 npm 节点自动处理 npm 中的工作，并将其与其他应用集成。

本页列出了 npm 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [npm 凭据](../credentials/npm.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Package（软件包）
	* Get Package Metadata（获取软件包元数据）
	* Get Package Versions（获取软件包版本）
	* Search for Packages（搜索软件包）
* Distribution Tag（分发标签）
	* Get All Tags（获取全部标签）
	* Update a Tag（更新标签）
