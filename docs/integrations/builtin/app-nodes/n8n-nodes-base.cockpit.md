# Cockpit 节点 <a href="#cockpit-node" id="cockpit-node"></a>

使用 Cockpit 节点自动处理 Cockpit 中的工作，并将其与其他应用集成。n8n 内置支持多种 Cockpit 功能，包括创建集合条目、存储表单提交的数据和获取单例。

本页列出了 Cockpit 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Cockpit 凭据](../credentials/cockpit.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Collection（集合）
    * Create a collection entry（创建集合条目）
    * Get all collection entries（获取集合中的全部条目）
    * Update a collection entry（更新集合条目）
* Form（表单）
    * Store data from a form submission（存储表单提交的数据）
* Singleton（单例）
    * Get a singleton（获取单例）
