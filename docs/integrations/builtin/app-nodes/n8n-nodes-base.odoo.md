# Odoo 节点 <a href="#odoo-node" id="odoo-node"></a>

使用 Odoo 节点自动处理 Odoo 中的工作，并将其与其他应用集成。n8n 内置支持多种 Odoo 功能，包括创建、更新、删除和获取合同、资源和销售机会。

本页列出了 Odoo 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Odoo 凭据](../credentials/odoo.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Contact（联系人）
    * Create a new contact（创建新联系人）
    * Delete a contact（删除联系人）
    * Get a contact（获取联系人）
    * Get all contacts（获取全部联系人）
    * Update a contact（更新联系人）
* Custom Resource（自定义资源）
    * Create a new item（创建新数据项）
    * Delete an item（删除数据项）
    * Get an item（获取数据项）
    * Get all items（获取全部数据项）
    * Update an item（更新数据项）
* Note（备注）
    * Create a new note（创建新备注）
    * Delete a note（删除备注）
    * Get a note（获取备注）
    * Get all notes（获取全部备注）
    * Update a note（更新备注）
* Opportunity（销售机会）
    * Create a new opportunity（创建新销售机会）
    * Delete an opportunity（删除销售机会）
    * Get an opportunity（获取销售机会）
    * Get all opportunities（获取全部销售机会）
    * Update an opportunity（更新销售机会）
