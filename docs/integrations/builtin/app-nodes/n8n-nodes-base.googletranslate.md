# Google Translate 节点 <a href="#google-translate-node" id="google-translate-node"></a>

使用 Google Translate 节点自动处理 Google Translate 中的工作，并将其与其他应用集成。n8n 内置支持多种 Google Translate 功能，包括语言翻译。

本页列出了 Google Translate 节点支持的操作，并提供更多资源的链接。

有关身份验证设置，请参阅 [Google Translate 凭据](../credentials/google/README.md)。
