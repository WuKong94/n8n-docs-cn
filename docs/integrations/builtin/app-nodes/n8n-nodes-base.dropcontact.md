# Dropcontact 节点 <a href="#dropcontact-node" id="dropcontact-node"></a>

使用 Dropcontact 节点自动处理 Dropcontact 中的工作，并将其与其他应用集成。n8n 内置支持多种 Dropcontact 功能，包括获取联系人。

本页列出了 Dropcontact 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Dropcontact 凭据](../credentials/dropcontact.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

**Contact（联系人）**
- Enrich（补全信息）
- Fetch Request（获取请求）
