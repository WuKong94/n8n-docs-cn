# Google Slides 节点 <a href="#google-slides-node" id="google-slides-node"></a>

使用 Google Slides 节点自动处理 Google Slides 中的工作，并将其与其他应用集成。n8n 内置支持多种 Google Slides 功能，包括创建演示文稿和获取页面。

本页列出了 Google Slides 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Google 凭据](../credentials/google/README.md)。
{% endhint %}

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/app-nodes/ai-tools.md" %}

## 操作 <a href="#operations" id="operations"></a>

* Page（页面）
    * Get a page（获取页面）
    * Get a thumbnail（获取缩略图）
* Presentation（演示文稿）
    * Create a presentation（创建演示文稿）
    * Get a presentation（获取演示文稿）
    * Get presentation slides（获取演示文稿的幻灯片）
    * Replace text in a presentation（替换演示文稿中的文字）
