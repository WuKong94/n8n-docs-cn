# Monica CRM 节点 <a href="#monica-crm-node" id="monica-crm-node"></a>

使用 Monica CRM 节点自动处理 Monica CRM 中的工作，并将其与其他应用集成。n8n 内置支持多种 Monica CRM 功能，包括创建、更新、删除和获取活动、通话、联系人、消息、任务及备注。

本页列出了 Monica CRM 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Monica CRM 凭据](../credentials/monicacrm.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Activity（活动）
    * Create an activity（创建活动）
    * Delete an activity（删除活动）
    * Retrieve an activity（获取活动）
    * Retrieve all activities（获取全部活动）
    * Update an activity（更新活动）
* Call（通话）
    * Create a call（创建通话）
    * Delete a call（删除通话）
    * Retrieve a call（获取通话）
    * Retrieve all calls（获取全部通话）
    * Update a call（更新通话）
* Contact（联系人）
    * Create a contact（创建联系人）
    * Delete a contact（删除联系人）
    * Retrieve a contact（获取联系人）
    * Retrieve all contacts（获取全部联系人）
    * Update a contact（更新联系人）
* Contact Field（联系人字段）
    * Create a contact field（创建联系人字段）
    * Delete a contact field（删除联系人字段）
    * Retrieve a contact field（获取联系人字段）
    * Update a contact field（更新联系人字段）
* Contact Tag（联系人标签）
    * Add（添加）
    * Remove（移除）
* Conversation（会话）
    * Create a conversation（创建会话）
    * Delete a conversation（删除会话）
    * Retrieve a conversation（获取会话）
    * Update a conversation（更新会话）
* Conversation Message（会话消息）
    * Add a message to a conversation（向会话添加消息）
    * Update a message in a conversation（更新会话中的消息）
* Journal Entry（日记条目）
    * Create a journal entry（创建日记条目）
    * Delete a journal entry（删除日记条目）
    * Retrieve a journal entry（获取日记条目）
    * Retrieve all journal entries（获取所有日记条目）
    * Update a journal entry（更新日记条目）
* Note（备注）
    * Create a note（创建备注）
    * Delete a note（删除备注）
    * Retrieve a note（获取备注）
    * Retrieve all notes（获取全部备注）
    * Update a note（更新备注）
* Reminder（提醒）
    * Create a reminder（创建提醒）
    * Delete a reminder（删除提醒）
    * Retrieve a reminder（获取提醒）
    * Retrieve all reminders（获取所有提醒）
    * Update a reminder（更新提醒）
* Tag（标签）
    * Create a tag（创建标签）
    * Delete a tag（删除标签）
    * Retrieve a tag（获取标签）
    * Retrieve all tags（获取全部标签）
    * Update a tag（更新标签）
* Task（任务）
    * Create a task（创建任务）
    * Delete a task（删除任务）
    * Retrieve a task（获取任务）
    * Retrieve all tasks（获取全部任务）
    * Update a task（更新任务）
