# SeaTable 节点 <a href="#seatable-node" id="seatable-node"></a>

使用 SeaTable 节点自动处理 SeaTable 中的工作，并将其与其他应用集成。n8n 内置支持多种 SeaTable 功能，包括创建、更新、删除和获取行。

本页列出了 SeaTable 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [SeaTable 凭据](../credentials/seatable.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Row（行）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
