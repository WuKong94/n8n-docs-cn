# Mandrill 节点 <a href="#mandrill-node" id="mandrill-node"></a>

使用 Mandrill 节点自动处理 Mandrill 中的工作，并将其与其他应用集成。n8n 支持通过 Mandrill 根据模板或 HTML 发送消息。

本页列出了 Mandrill 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Mandrill 凭据](../credentials/mandrill.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Message（消息）
    * Send message based on template.（根据模板发送消息）
    * Send message based on HTML.（根据 HTML 发送消息）
