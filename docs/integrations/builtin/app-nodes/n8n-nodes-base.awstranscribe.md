# AWS Transcribe 节点 <a href="#aws-transcribe-node" id="aws-transcribe-node"></a>

使用 AWS Transcribe 节点自动处理 AWS Transcribe 中的工作，并将其与其他应用集成。n8n 内置支持多种 AWS Transcribe 功能，包括创建、删除和获取转录任务。

本页列出了 AWS Transcribe 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [AWS Transcribe 凭据](../credentials/aws.md)。
{% endhint %}
