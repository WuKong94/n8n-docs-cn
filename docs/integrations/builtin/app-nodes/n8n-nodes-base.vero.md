# Vero 节点 <a href="#vero-node" id="vero-node"></a>

使用 Vero 节点自动处理 Vero 中的工作，并将其与其他应用集成。n8n 内置支持多种 Vero 功能，包括创建和删除用户。

本页列出了 Vero 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Vero 凭据](../credentials/vero.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* User（用户）
    * Create or update a user profile（创建或更新用户资料）
    * Change a users identifier（更改用户标识符）
    * Unsubscribe a user.（取消用户订阅）
    * Resubscribe a user.（恢复用户订阅）
    * Delete a user.（删除用户）
    * Adds a tag to a users profile.（为用户资料添加标签）
    * Removes a tag from a users profile.（从用户资料移除标签）
* Event（事件）
    * Track an event for a specific customer（跟踪指定客户的事件）
