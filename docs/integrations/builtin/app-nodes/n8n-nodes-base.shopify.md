# Shopify 节点 <a href="#shopify-node" id="shopify-node"></a>

使用 Shopify 节点自动处理 Shopify 中的工作，并将其与其他应用集成。n8n 内置支持多种 Shopify 功能，包括创建、更新、删除和获取订单与产品。

本页列出了 Shopify 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Shopify 凭据](../credentials/shopify.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Order（订单）
    * Create an order（创建订单）
    * Delete an order（删除订单）
    * Get an order（获取订单）
    * Get all orders（获取全部订单）
    * Update an order（更新订单）
* Product（产品）
    * Create a product（创建产品）
    * Delete a product（删除产品）
    * Get a product（获取产品）
    * Get all products（获取全部产品）
    * Update a product（更新产品）
