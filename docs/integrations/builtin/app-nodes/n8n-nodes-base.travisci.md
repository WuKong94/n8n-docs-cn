# Travis CI 节点 <a href="#travis-ci-node" id="travis-ci-node"></a>

使用 Travis CI 节点自动处理 Travis CI 中的工作，并将其与其他应用集成。n8n 内置支持多种 Travis CI 功能，包括取消和获取构建。

本页列出了 Travis CI 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Travis CI 凭据](../credentials/travisci.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Build（构建）
    * Cancel a build（取消构建）
    * Get a build（获取构建）
    * Get all builds（获取全部构建）
    * Restart a build（重新启动构建）
    * Trigger a build（触发构建）
