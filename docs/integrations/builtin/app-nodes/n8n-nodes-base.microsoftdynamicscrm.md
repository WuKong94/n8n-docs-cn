# Microsoft Dynamics CRM 节点 <a href="#microsoft-dynamics-crm-node" id="microsoft-dynamics-crm-node"></a>

使用 Microsoft Dynamics CRM 节点自动处理 Microsoft Dynamics CRM 中的工作，并将其与其他应用集成。n8n 内置支持创建、更新、删除和获取 Microsoft Dynamics CRM 账户。

本页列出了 Microsoft Dynamics CRM 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Microsoft 凭据](../credentials/microsoft.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Account（账户）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
