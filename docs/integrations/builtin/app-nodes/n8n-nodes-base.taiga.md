# Taiga 节点 <a href="#taiga-node" id="taiga-node"></a>

使用 Taiga 节点自动处理 Taiga 中的工作，并将其与其他应用集成。n8n 内置支持多种 Taiga 功能，包括创建、更新、删除和获取议题。

本页列出了 Taiga 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Taiga 凭据](../credentials/taiga.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

- **Issue（问题）**
    - Create an issue（创建问题）
    - Delete an issue（删除问题）
    - Get an issue（获取问题）
    - Get all issues（获取全部问题）
    - Update an issue（更新问题）
