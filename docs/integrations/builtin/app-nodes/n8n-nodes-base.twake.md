# Twake 节点 <a href="#twake-node" id="twake-node"></a>

使用 Twake 节点自动处理 Twake 中的工作，并将其与其他应用集成。n8n 支持通过 Twake 发送消息。

本页列出了 Twake 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Twake 凭据](../credentials/twake.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Message（消息）
    * Send a message（发送消息）
