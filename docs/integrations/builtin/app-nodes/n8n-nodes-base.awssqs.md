# AWS SQS 节点 <a href="#aws-sqs-node" id="aws-sqs-node"></a>

使用 AWS SQS 节点自动处理 AWS SQS 中的工作，并将其与其他应用集成。n8n 内置支持多种 AWS SQS 功能，包括发送消息。

本页列出了 AWS SQS 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [AWS SQS 凭据](../credentials/aws.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Send a message to a queue.（向队列发送消息）
