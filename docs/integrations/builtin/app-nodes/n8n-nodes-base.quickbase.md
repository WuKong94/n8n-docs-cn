# Quick Base 节点 <a href="#quick-base-node" id="quick-base-node"></a>

使用 Quick Base 节点自动处理 Quick Base 中的工作，并将其与其他应用集成。n8n 内置支持多种 Quick Base 功能，包括创建、更新、删除和获取记录，以及获取字段和下载文件。

本页列出了 Quick Base 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Quick Base 凭据](../credentials/quickbase.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Field（字段）
    * Get all fields（获取全部字段）
* File（文件）
    * Delete a file（删除文件）
    * Download a file（下载文件）
* Record（记录）
    * Create a record（创建记录）
    * Delete a record（删除记录）
    * Get all records（获取全部记录）
    * Update a record（更新记录）
    * Upsert a record（插入或更新记录）
* Report（报告）
    * Get a report（获取报告）
    * Run a report（运行报告）
