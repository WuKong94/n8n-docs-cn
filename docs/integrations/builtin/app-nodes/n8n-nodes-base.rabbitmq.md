# RabbitMQ 节点 <a href="#rabbitmq-node" id="rabbitmq-node"></a>

使用 RabbitMQ 节点自动处理 RabbitMQ 中的工作，并将其与其他应用集成。n8n 内置支持多种 RabbitMQ 功能，包括接收和转发消息。

本页列出了 RabbitMQ 节点支持的操作，并提供更多资源的链接。
