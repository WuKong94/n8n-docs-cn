# Netlify 节点 <a href="#netlify-node" id="netlify-node"></a>

使用 Netlify 节点自动处理 Netlify 中的工作，并将其与其他应用集成。n8n 内置支持多种 Netlify 功能，包括获取和取消部署，以及删除和获取站点。

本页列出了 Netlify 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Netlify 凭据](../credentials/netlify.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Deploy（部署）
    * Cancel a deployment（取消部署）
    * Create a new deployment（创建部署）
    * Get a deployment（获取部署）
    * Get all deployments（获取全部部署）
* Site（站点）
    * Delete a site（删除站点）
    * Get a site（获取站点）
    * Returns all sites（返回全部站点）
