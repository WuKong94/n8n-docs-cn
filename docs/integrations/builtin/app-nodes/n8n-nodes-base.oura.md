# Oura 节点 <a href="#oura-node" id="oura-node"></a>

使用 Oura 节点自动处理 Oura 中的工作，并将其与其他应用集成。n8n 内置支持多种 Oura 功能，包括获取个人资料和摘要。

本页列出了 Oura 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Oura 凭据](../credentials/oura.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Profile（个人资料）
    * Get the user's personal information.（获取用户的个人信息）
* Summary（摘要）
    * Get the user's activity summary.（获取用户的活动摘要）
    * Get the user's readiness summary.（获取用户的准备状态摘要）
    * Get the user's sleep summary（获取用户的睡眠摘要）
