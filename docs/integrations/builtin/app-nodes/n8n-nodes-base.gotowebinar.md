# GoToWebinar 节点 <a href="#gotowebinar-node" id="gotowebinar-node"></a>

使用 GoToWebinar 节点自动处理 GoToWebinar 中的工作，并将其与其他应用集成。n8n 内置支持多种 GoToWebinar 功能，包括创建、获取和删除参会者、组织者及报名者。

本页列出了 GoToWebinar 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [GoToWebinar 凭据](../credentials/gotowebinar.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Attendee（参会者）
    * Get（获取）
    * Get All（获取全部）
    * Get Details（获取详情）
* Co-Organizer（联合组织者）
    * Create（创建）
    * Delete（删除）
    * Get All（获取全部）
    * Re-invite（重新邀请）
* Panelist（嘉宾）
    * Create（创建）
    * Delete（删除）
    * Get All（获取全部）
    * Re-invite（重新邀请）
* Registrant（报名者）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
* Session（场次）
    * Get（获取）
    * Get All（获取全部）
    * Get Details（获取详情）
* Webinar（网络研讨会）
    * Create（创建）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
