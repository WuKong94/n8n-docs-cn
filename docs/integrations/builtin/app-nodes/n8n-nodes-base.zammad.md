# Zammad 节点 <a href="#zammad-node" id="zammad-node"></a>

使用 Zammad 节点自动处理 Zammad 中的工作，并将其与其他应用集成。n8n 内置支持多种 Zammad 功能，包括创建、检索和删除群组与组织。

本页列出了 Zammad 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Zammad 凭据](../credentials/zammad.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Group（群组）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get many（获取多条）
    * Update（更新）
* Organization（组织）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get many（获取多条）
    * Update（更新）
* Ticket（工单）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get many（获取多条）
    * Update（更新）
* User（用户）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get many（获取多条）
	* Get self（获取当前用户）
    * Update（更新）
