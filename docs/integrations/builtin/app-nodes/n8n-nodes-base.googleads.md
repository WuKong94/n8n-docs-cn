# Google Ads 节点 <a href="#google-ads-node" id="google-ads-node"></a>

使用 Google Ads 节点自动处理 Google Ads 中的工作，并将其与其他应用集成。n8n 内置支持多种 Google Ads 功能，包括获取营销活动。

本页列出了 Google Ads 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Google Ads 凭据](../credentials/google/README.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Campaign（营销活动）
    * Get all campaigns（获取全部营销活动）
    * Get a campaign（获取营销活动）
