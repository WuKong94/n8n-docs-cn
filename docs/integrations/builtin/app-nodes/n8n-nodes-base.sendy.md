# Sendy 节点 <a href="#sendy-node" id="sendy-node"></a>

使用 Sendy 节点自动处理 Sendy 中的工作，并将其与其他应用集成。n8n 内置支持多种 Sendy 功能，包括创建营销活动，以及添加、统计、删除和获取订阅者。

本页列出了 Sendy 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Sendy 凭据](../credentials/sendy.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Campaign（营销活动）
    * Create a campaign（创建营销活动）
* Subscriber（订阅者）
    * Add a subscriber to a list（将订阅者添加到列表）
    * Count subscribers（统计订阅者数量）
    * Delete a subscriber from a list（从列表中删除订阅者）
    * Unsubscribe user from a list（取消用户对列表的订阅）
    * Get the status of subscriber（获取订阅者状态）
