# OpenThesaurus 节点 <a href="#openthesaurus-node" id="openthesaurus-node"></a>

使用 OpenThesaurus 节点自动处理 OpenThesaurus 中的工作，并将其与其他应用集成。n8n 支持查找德语单词的同义词。

本页列出了 OpenThesaurus 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

OpenThesaurus 节点无需身份验证。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Get synonyms for a German word in German（获取德语单词的德语同义词）
