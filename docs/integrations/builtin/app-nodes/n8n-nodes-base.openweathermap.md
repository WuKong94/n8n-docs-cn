# OpenWeatherMap 节点 <a href="#openweathermap-node" id="openweathermap-node"></a>

使用 OpenWeatherMap 节点自动处理 OpenWeatherMap 中的工作，并将其与其他应用集成。n8n 支持通过 OpenWeatherMap 获取当前和未来的天气数据。

本页列出了 OpenWeatherMap 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [OpenWeatherMap 凭据](../credentials/openweathermap.md)。
{% endhint %}

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/app-nodes/ai-tools.md" %}

## 操作 <a href="#operations" id="operations"></a>

* Returns the current weather data（返回当前天气数据）
* Returns the weather data for the next 5 days（返回未来 5 天的天气数据）
