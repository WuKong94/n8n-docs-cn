# Drift 节点 <a href="#drift-node" id="drift-node"></a>

使用 Drift 节点自动处理 Drift 中的工作，并将其与其他应用集成。n8n 内置支持多种 Drift 功能，包括创建、更新、删除和获取联系人。

本页列出了 Drift 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Drift 凭据](../credentials/drift.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Contact（联系人）
    * Create a contact（创建联系人）
    * Get custom attributes（获取自定义属性）
    * Delete a contact（删除联系人）
    * Get a contact（获取联系人）
    * Update a contact（更新联系人）
