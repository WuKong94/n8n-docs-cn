# Mailjet 节点 <a href="#mailjet-node" id="mailjet-node"></a>

使用 Mailjet 节点自动处理 Mailjet 中的工作，并将其与其他应用集成。n8n 内置支持多种 Mailjet 功能，包括发送电子邮件和短信。

本页列出了 Mailjet 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Mailjet 凭据](../credentials/mailjet.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Email（电子邮件）
    * Send an email（发送电子邮件）
    * Send an email template（发送电子邮件模板）
* SMS（短信）
    * Send an SMS（发送短信）
