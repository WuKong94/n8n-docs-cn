# marketstack 节点 <a href="#marketstack-node" id="marketstack-node"></a>

使用 marketstack 节点自动处理 marketstack 中的工作，并将其与其他应用集成。n8n 内置支持多种 marketstack 功能，包括获取交易所、日终数据和证券代码。

本页列出了 marketstack 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [marketstack 凭据](../credentials/marketstack.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* End-of-Day Data（日终数据）
    * Get All（获取全部）
* Exchange（交易所）
    * Get（获取）
* Ticker（证券代码）
    * Get（获取）
