# Google Cloud Firestore 节点 <a href="#google-cloud-firestore-node" id="google-cloud-firestore-node"></a>

使用 Google Cloud Firestore 节点自动处理 Google Cloud Firestore 中的工作，并将其与其他应用集成。n8n 内置支持多种 Google Cloud Firestore 功能，包括创建、删除和获取文档。

本页列出了 Google Cloud Firestore 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Google 凭据](../credentials/google/README.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Document（文档）
    * Create a document（创建文档）
    * Create/Update a document（创建或更新文档）
    * Delete a document（删除文档）
    * Get a document（获取文档）
    * Get all documents from a collection（获取集合中的全部文档）
    * Runs a query against your documents（对文档执行查询）
* Collection（集合）
    * Get all root collections（获取全部根集合）
