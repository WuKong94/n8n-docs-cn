# Webex by Cisco 节点 <a href="#webex-by-cisco-node" id="webex-by-cisco-node"></a>

使用 Webex by Cisco 节点自动处理 Webex 中的工作，并将 Webex 与其他应用集成。n8n 内置支持多种 Webex 功能，包括创建、获取、更新和删除会议及消息。

本页列出了 Webex 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

身份验证设置说明，请参阅 [Webex 凭据](../credentials/ciscowebex.md)。
{% endhint %}
{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Webex 集成](https://n8n.io/integrations/webex-by-cisco/)列表。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Meeting（会议）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Message（消息）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
