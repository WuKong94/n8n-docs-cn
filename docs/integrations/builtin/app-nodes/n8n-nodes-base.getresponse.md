# GetResponse 节点 <a href="#getresponse-node" id="getresponse-node"></a>

使用 GetResponse 节点自动处理 GetResponse 中的工作，并将其与其他应用集成。n8n 内置支持多种 GetResponse 功能，包括创建、更新、删除和获取联系人。

本页列出了 GetResponse 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [GetResponse 凭据](../credentials/getresponse.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Contact（联系人）
    * Create a new contact（创建新联系人）
    * Delete a contact（删除联系人）
    * Get a contact（获取联系人）
    * Get all contacts（获取全部联系人）
    * Update contact properties（更新联系人属性）
