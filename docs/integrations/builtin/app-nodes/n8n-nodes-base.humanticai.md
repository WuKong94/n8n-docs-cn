# Humantic AI 节点 <a href="#humantic-ai-node" id="humantic-ai-node"></a>

使用 Humantic AI 节点自动处理 Humantic AI 中的工作，并将其与其他应用集成。n8n 内置支持多种 Humantic AI 功能，包括创建、检索和更新个人资料。

本页列出了 Humantic AI 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Humantic AI 凭据](../credentials/humanticai.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Profile（个人资料）
    * Create a profile（创建个人资料）
    * Retrieve a profile（检索个人资料）
    * Update a profile（更新个人资料）
