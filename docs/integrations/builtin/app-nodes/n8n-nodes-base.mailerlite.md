# MailerLite 节点 <a href="#mailerlite-node" id="mailerlite-node"></a>

使用 MailerLite 节点自动处理 MailerLite 中的工作，并将其与其他应用集成。n8n 内置支持多种 MailerLite 功能，包括创建、更新、删除和获取订阅者。

本页列出了 MailerLite 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [MailerLite 凭据](../credentials/mailerlite.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Subscriber（订阅者）
    * Create a new subscriber（创建新订阅者）
    * Get an subscriber（获取订阅者）
    * Get all subscribers（获取全部订阅者）
    * Update an subscriber（更新订阅者）
