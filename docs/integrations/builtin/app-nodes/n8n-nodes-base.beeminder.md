# Beeminder 节点 <a href="#beeminder-node" id="beeminder-node"></a>

使用 Beeminder 节点自动处理 Beeminder 中的工作，并将其与其他应用集成。n8n 内置支持多种 Beeminder 功能，包括创建、删除和更新数据点。

本页列出了 Beeminder 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Beeminder 凭据](../credentials/beeminder.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

**data point（数据点）**
- 为目标创建数据点
- 删除数据点
- 获取目标的全部数据点
- 更新数据点
