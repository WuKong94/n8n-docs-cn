# E-goi 节点 <a href="#e-goi-node" id="e-goi-node"></a>

使用 E-goi 节点自动处理 E-goi 中的工作，并将其与其他应用集成。n8n 内置支持多种 E-goi 功能，包括创建、更新、删除及获取联系人。

本页列出了 E-goi 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [E-goi 凭据](../credentials/egoi.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

**Contact**（联系人）

- Create a member（创建成员）
- Get a member（获取成员）
- Get all members（获取所有成员）
- Update a member（更新成员）
