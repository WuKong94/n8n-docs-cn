# MSG91 节点 <a href="#msg91-node" id="msg91-node"></a>

使用 MSG91 节点自动处理 MSG91 中的工作，并将其与其他应用集成。n8n 支持通过 MSG91 发送短信。

本页列出了 MSG91 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [MSG91 凭据](../credentials/msg91.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* SMS（短信）
    * Send SMS（发送短信）

## 模板与示例 <a href="#templates-and-examples" id="templates-and-examples"></a>


[浏览 MSG91 集成模板](https://n8n.io/integrations/msg91)，或[搜索所有模板](https://n8n.io/workflows/)

## 查找 Sender ID <a href="#find-your-sender-id" id="find-your-sender-id"></a>

1. 登录 MSG91 控制台。
2. 在左侧面板中选择 **Sender Id**（发送方 ID）。
3. 如果还没有发送方 ID，选择 **Add Sender Id +**（添加发送方 ID），填写详情，再选择 **Save Sender Id**（保存发送方 ID）。
