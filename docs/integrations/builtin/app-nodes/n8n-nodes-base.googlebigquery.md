# Google BigQuery 节点 <a href="#google-bigquery-node" id="google-bigquery-node"></a>

使用 Google BigQuery 节点自动处理 Google BigQuery 中的工作，并将其与其他应用集成。n8n 内置支持多种 Google BigQuery 功能，包括创建和检索记录。

本页列出了 Google BigQuery 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Google BigQuery 凭据](../credentials/google/README.md)。
{% endhint %}
