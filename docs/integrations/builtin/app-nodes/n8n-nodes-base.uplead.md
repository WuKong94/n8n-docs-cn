# UpLead 节点 <a href="#uplead-node" id="uplead-node"></a>

使用 UpLead 节点自动处理 UpLead 中的工作，并将其与其他应用集成。n8n 支持多种 UpLead 操作，包括获取公司信息。

本页列出了 UpLead 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [UpLead 凭据](../credentials/uplead.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Company（公司）
    * Enrich（补全信息）
* Person（人员）
    * Enrich（补全信息）
