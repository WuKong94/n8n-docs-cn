# Intercom 节点 <a href="#intercom-node" id="intercom-node"></a>

使用 Intercom 节点自动处理 Intercom 中的工作，并将其与其他应用集成。n8n 内置支持多种 Intercom 功能，包括创建、更新、删除和获取公司、销售线索及用户。

本页列出了 Intercom 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Intercom 凭据](../credentials/intercom.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Company（公司）
    * Create a new company（创建新公司）
    * Get data of a company（获取公司数据）
    * Get data of all companies（获取全部公司的数据）
    * Update a company（更新公司）
    * List company's users（列出公司的用户）
* Lead（销售线索）
    * Create a new lead（创建新销售线索）
    * Delete a lead（删除销售线索）
    * Get data of a lead（获取销售线索数据）
    * Get data of all leads（获取全部销售线索的数据）
    * Update new lead（更新新销售线索）
* User（用户）
    * Create a new user（创建新用户）
    * Delete a user（删除用户）
    * Get data of a user（获取用户数据）
    * Get data of all users（获取全部用户的数据）
    * Update a user（更新用户）
