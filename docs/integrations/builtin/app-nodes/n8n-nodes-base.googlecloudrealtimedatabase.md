# Google Cloud Realtime Database 节点 <a href="#google-cloud-realtime-database-node" id="google-cloud-realtime-database-node"></a>

使用 Google Cloud Realtime Database 节点自动处理 Google Cloud Realtime Database 中的工作，并将其与其他应用集成。n8n 内置支持多种 Google Cloud Realtime Database 功能，包括对数据库进行写入、删除、获取和追加操作。

本页列出了 Google Cloud Realtime Database 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Google Cloud Realtime Database 凭据](../credentials/google/README.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Write data to a database（向数据库写入数据）
* Delete data from a database（从数据库删除数据）
* Get a record from a database（从数据库获取记录）
* Append to a list of data（向数据列表追加内容）
* Update item on a database（更新数据库中的数据项）
