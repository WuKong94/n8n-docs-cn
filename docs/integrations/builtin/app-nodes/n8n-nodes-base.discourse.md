# Discourse 节点 <a href="#discourse-node" id="discourse-node"></a>

使用 Discourse 节点自动处理 Discourse 中的工作，并将其与其他应用集成。n8n 内置支持多种 Discourse 功能，包括创建、获取、更新和移除分类、群组、帖子和用户。

本页列出了 Discourse 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Discourse 凭据](../credentials/discourse.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Category（分类）
    * Create a category（创建分类）
    * Get all categories（获取全部分类）
    * Update a category（更新分类）
* Group（群组）
    * Create a group（创建群组）
    * Get a group（获取群组）
    * Get all groups（获取全部群组）
    * Update a group（更新群组）
* Post（帖子）
    * Create a post（创建帖子）
    * Get a post（获取帖子）
    * Get all posts（获取全部帖子）
    * Update a post（更新帖子）
* User（用户）
    * Create a user（创建用户）
    * Get a user（获取用户）
    * Get all users（获取全部用户）
* User Group（用户组）
    * Create a user to group（向用户组添加用户）
    * Remove user from group（从用户组移除用户）
