# Freshservice 节点 <a href="#freshservice-node" id="freshservice-node"></a>

使用 Freshservice 节点自动处理 Freshservice 中的工作，并将其与其他应用集成。n8n 内置支持多种 Freshservice 功能，包括创建、更新、删除和获取服务人员信息及部门。

本页列出了 Freshservice 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Freshservice 凭据](../credentials/freshservice.md)。
{% endhint %}
