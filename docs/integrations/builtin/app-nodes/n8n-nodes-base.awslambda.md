# AWS Lambda 节点 <a href="#aws-lambda-node" id="aws-lambda-node"></a>

使用 AWS Lambda 节点自动处理 AWS Lambda 中的工作，并将其与其他应用集成。n8n 内置支持多种 AWS Lambda 功能，包括调用函数。

本页列出了 AWS Lambda 节点支持的操作，并提供更多资源的链接。
