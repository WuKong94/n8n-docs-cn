# MessageBird 节点 <a href="#messagebird-node" id="messagebird-node"></a>

使用 MessageBird 节点自动处理 MessageBird 中的工作，并将其与其他应用集成。n8n 内置支持多种 MessageBird 功能，包括发送消息和获取余额。

本页列出了 MessageBird 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [MessageBird 凭据](../credentials/messagebird.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* SMS（短信）
    * Send text messages (SMS)（发送文本消息（短信））
* Balance（余额）
    * Get the balance（获取余额）
