# UptimeRobot 节点 <a href="#uptimerobot-node" id="uptimerobot-node"></a>

使用 UptimeRobot 节点自动处理 UptimeRobot 中的工作，并将其与其他应用集成。n8n 内置支持多种 UptimeRobot 功能，包括创建和删除告警，以及获取账户详情。

本页列出了 UptimeRobot 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [UptimeRobot 凭据](../credentials/uptimerobot.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Account（账户）
    * Get account details（获取账户详情）
* Alert Contact（告警联系人）
    * Create an alert contact（创建告警联系人）
    * Delete an alert contact（删除告警联系人）
    * Get an alert contact（获取告警联系人）
    * Get all alert contacts（获取所有告警联系人）
    * Update an alert contact（更新告警联系人）
* Maintenance Window（维护窗口）
    * Create a maintenance window（创建维护窗口）
    * Delete a maintenance window（删除维护窗口）
    * Get a maintenance window（获取维护窗口）
    * Get all a maintenance windows（获取所有维护窗口）
    * Update a maintenance window（更新维护窗口）
* Monitor（监控器）
    * Create a monitor（创建监控器）
    * Delete a monitor（删除监控器）
    * Get a monitor（获取监控器）
    * Get all monitors（获取所有监控器）
    * Reset a monitor（重置监控器）
    * Update a monitor（更新监控器）
* Public Status Page（公开状态页面）
    * Create a public status page（创建公开状态页面）
    * Delete a public status page（删除公开状态页面）
    * Get a public status page（获取公开状态页面）
    * Get all a public status pages（获取所有公开状态页面）
