# QuickChart 节点 <a href="#quickchart-node" id="quickchart-node"></a>

使用 QuickChart 节点自动处理 QuickChart 中的工作，并将其与其他应用集成。n8n 内置支持多种 QuickChart 图表类型，包括条形图、圆环图、折线图、饼图和极坐标图。

本页列出了 QuickChart 节点支持的操作，并提供更多资源的链接。

{% include "../../../reusable-content/.gitbook/includes/integrations/builtin/app-nodes/ai-tools.md" %}

## 操作 <a href="#operations" id="operations"></a>

选择图表类型来创建图表：

* Chart Type（图表类型）
	* Bar Chart（条形图）
	* Doughnut Chart（圆环图）
	* Line Chart（折线图）
	* Pie Chart（饼图）
	* Polar Chart（极坐标图）
