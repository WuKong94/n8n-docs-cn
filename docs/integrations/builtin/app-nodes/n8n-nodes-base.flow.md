# Flow 节点 <a href="#flow-node" id="flow-node"></a>


{% hint style="warning" %}
**功能可用范围**

Flow 服务已停止运营，其 API 不再响应，因此 Flow 和 Flow Trigger 节点无法连接该服务。使用这些节点的工作流会失败。请移除这些节点，或切换到其他服务。
{% endhint %}

使用 Flow 节点自动处理 Flow 中的工作，并将其与其他应用集成。n8n 内置支持多种 Flow 功能，包括创建、更新和获取任务。

本页列出了 Flow 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Flow 凭据](../credentials/flow.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Task（任务）
    * Create a new task（创建新任务）
    * Update a task（更新任务）
    * Get a task（获取任务）
    * Get all the tasks（获取全部任务）
