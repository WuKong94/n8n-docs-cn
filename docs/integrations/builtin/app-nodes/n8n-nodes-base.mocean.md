# Mocean 节点 <a href="#mocean-node" id="mocean-node"></a>

使用 Mocean 节点自动处理 Mocean 中的工作，并将其与其他应用集成。n8n 内置支持多种 Mocean 功能，包括发送短信和语音消息。

本页列出了 Mocean 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Mocean 凭据](../credentials/mocean.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* SMS（短信）
    * Send SMS/Voice message（发送短信或语音消息）
* Voice（语音）
    * Send SMS/Voice message（发送短信或语音消息）
