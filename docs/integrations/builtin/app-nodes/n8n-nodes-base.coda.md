# Coda 节点 <a href="#coda-node" id="coda-node"></a>

使用 Coda 节点自动处理 Coda 中的工作，并将其与其他应用集成。n8n 内置支持多种 Coda 功能，包括创建、获取和删除控件、公式、表格和视图。

本页列出了 Coda 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Coda 凭据](../credentials/coda.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Control（控件）
    * Get a control（获取控件）
    * Get all controls（获取全部控件）
* Formula（公式）
    * Get a formula（获取公式）
    * Get all formulas（获取全部公式）
* Table（表）
    * Create/Insert a row（创建或插入行）
    * Delete one or multiple rows（删除一行或多行）
    * Get all columns（获取全部列）
    * Get all the rows（获取全部行）
    * Get a column（获取列）
    * Get a row（获取行）
    * Pushes a button（按下按钮）
* View（视图）
    * Delete view row（删除视图行）
    * Get a view（获取视图）
    * Get all views（获取全部视图）
    * Get all views columns（获取视图的全部列）
    * Get all views rows（获取视图的全部行）
    * Update row（更新行）
    * Push view button（按下视图按钮）
