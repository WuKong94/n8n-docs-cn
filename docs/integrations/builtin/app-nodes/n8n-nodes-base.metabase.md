# Metabase 节点 <a href="#metabase-node" id="metabase-node"></a>

使用 Metabase 节点自动处理 Metabase 中的工作，并将其与其他应用集成。n8n 内置支持多种 Metabase 功能，包括添加和获取告警、数据库、指标和问题。

本页列出了 Metabase 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Metabase 凭据](../credentials/metabase.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Alert（告警）
    * Get（获取）
    * Get All（获取全部）
* Database（数据库）
    * Add（添加）
    * Get All（获取全部）
    * Get Fields（获取字段）
* Metric（指标）
    * Get（获取）
    * Get All（获取全部）
* Question（问题）
    * Get（获取）
    * Get All（获取全部）
    * Result Data（结果数据）
