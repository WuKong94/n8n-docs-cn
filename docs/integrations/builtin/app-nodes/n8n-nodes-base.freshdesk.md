# Freshdesk 节点 <a href="#freshdesk-node" id="freshdesk-node"></a>

使用 Freshdesk 节点自动处理 Freshdesk 中的工作，并将其与其他应用集成。n8n 内置支持多种 Freshdesk 功能，包括创建、更新、删除和获取联系人及工单。

本页列出了 Freshdesk 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Freshdesk 凭据](../credentials/freshdesk.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Contact（联系人）
    * Create a new contact（创建新联系人）
    * Delete a contact（删除联系人）
    * Get a contact（获取联系人）
    * Get all contacts（获取全部联系人）
    * Update a contact（更新联系人）
* Ticket（工单）
    * Create a new ticket（创建新工单）
    * Delete a ticket（删除工单）
    * Get a ticket（获取工单）
    * Get all tickets（获取全部工单）
    * Update a ticket（更新工单）
