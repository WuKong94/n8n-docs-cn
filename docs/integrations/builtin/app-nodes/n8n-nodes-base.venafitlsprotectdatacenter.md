# Venafi TLS Protect Datacenter 节点 <a href="#venafi-tls-protect-datacenter-node" id="venafi-tls-protect-datacenter-node"></a>

使用 Venafi TLS Protect Datacenter 节点自动处理 Venafi TLS Protect Datacenter 中的工作，并将其与其他应用集成。n8n 内置支持多种 Venafi TLS Protect Datacenter 功能，包括创建、删除和获取证书。

本页列出了 Venafi TLS Protect Datacenter 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Venafi TLS Protect Datacenter 凭据](../credentials/venafitlsprotectdatacenter.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Certificate（证书）
	* Create（创建）
	* Delete（删除）
	* Download（下载）
	* Get（获取）
	* Get Many（获取多条）
	* Renew（续期）
* Policy（策略）
	* Get（获取）
