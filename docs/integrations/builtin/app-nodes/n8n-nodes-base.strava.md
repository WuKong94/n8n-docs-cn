# Strava 节点 <a href="#strava-node" id="strava-node"></a>

使用 Strava 节点自动处理 Strava 中的工作，并将其与其他应用集成。n8n 内置支持多种 Strava 功能，包括创建活动和获取活动信息。

本页列出了 Strava 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Strava 凭据](../credentials/strava.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Activity（活动）
    * Create a new activity（创建新活动）
    * Get an activity（获取活动）
    * Get all activities（获取全部活动）
    * Get all activity comments（获取活动的全部评论）
    * Get all activity kudos（获取活动的全部点赞）
    * Get all activity laps（获取活动的全部分圈记录）
    * Get all activity zones（获取活动的全部区间数据）
    * Update an activity（更新活动）
