# AWS SNS 节点 <a href="#aws-sns-node" id="aws-sns-node"></a>

使用 AWS SNS 节点自动处理 AWS SNS 中的工作，并将其与其他应用集成。n8n 内置支持多种 AWS SNS 功能，包括发布消息。

本页列出了 AWS SNS 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [AWS SNS 凭据](../credentials/aws.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Publish a message to a topic（向主题发布消息）
