# Copper 节点 <a href="#copper-node" id="copper-node"></a>

使用 Copper 节点自动处理 Copper 中的工作，并将其与其他应用集成。n8n 内置支持多种 Copper 功能，包括获取、更新、删除和创建公司、客户来源、销售线索、项目和任务。

本页列出了 Copper 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Copper 凭据](../credentials/copper.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Company（公司）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Customer Source（客户来源）
    * Get All（获取全部）
* Lead（销售线索）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Opportunity（销售机会）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Person（人员）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Project（项目）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* Task（任务）
    * Create（创建）
    * Delete（删除）
    * Get（获取）
    * Get All（获取全部）
    * Update（更新）
* User（用户）
    * Get All（获取全部）
