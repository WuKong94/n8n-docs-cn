# PostHog 节点 <a href="#posthog-node" id="posthog-node"></a>

使用 PostHog 节点自动处理 PostHog 中的工作，并将其与其他应用集成。n8n 内置支持多种 PostHog 功能，包括创建别名、事件和身份标识，以及跟踪页面。

本页列出了 PostHog 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [PostHog 凭据](../credentials/posthog.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Alias（别名）
    * Create an alias（创建别名）
* Event（事件）
    * Create an event（创建事件）
* Identity（身份标识）
    * Create（创建）
* Track（跟踪）
    * Track a page（跟踪页面）
    * Track a screen（跟踪屏幕）
