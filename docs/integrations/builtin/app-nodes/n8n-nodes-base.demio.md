# Demio 节点 <a href="#demio-node" id="demio-node"></a>

使用 Demio 节点自动处理 Demio 中的工作，并将其与其他应用集成。n8n 内置支持多种 Demio 功能，包括获取和登记事件及报告。

本页列出了 Demio 节点支持的操作，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

有关身份验证设置，请参阅 [Demio 凭据](../credentials/demio.md)。
{% endhint %}

## 操作 <a href="#operations" id="operations"></a>

* Event（事件）
    * Get an event（获取事件）
    * Get all events（获取全部事件）
    * Register someone to an event（为某人报名参加活动）
* Report（报告）
    * Get an event report（获取活动报告）
