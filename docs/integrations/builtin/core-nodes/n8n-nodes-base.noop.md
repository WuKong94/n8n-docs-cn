# No Operation, do nothing（不执行操作） <a href="#no-operation-do-nothing" id="no-operation-do-nothing"></a>

不希望执行任何操作时，可以使用 No Operation, do nothing 节点。此节点用于提高工作流的可读性，并明确数据流在何处停止，帮助其他人从视觉上更好地理解工作流。
