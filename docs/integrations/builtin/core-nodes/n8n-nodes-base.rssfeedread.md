# RSS Read（读取 RSS） <a href="#rss-read" id="rss-read"></a>

使用 RSS Read 节点读取互联网上发布的 RSS 订阅源数据。

## 节点参数 <a href="#node-parameters" id="node-parameters"></a>

- **URL**：输入要读取的 RSS 订阅源 URL。

## 节点选项 <a href="#node-options" id="node-options"></a>

* **Ignore SSL Issues**（忽略 SSL 问题）：选择 n8n 是否忽略 SSL/TLS 验证，开启时忽略，关闭时不忽略。
