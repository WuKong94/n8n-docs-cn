# SSE Trigger（SSE 触发器） 节点 <a href="#sse-trigger-node" id="sse-trigger-node"></a>

Server-Sent Events（SSE，服务器发送事件）是一种服务器推送技术，允许客户端通过 HTTP 连接接收服务器的自动更新。SSE Trigger 节点用于接收服务器发送事件。

## 节点参数 <a href="#node-parameters" id="node-parameters"></a>

SSE Trigger 节点只有一个参数 **URL**。输入要从中接收服务器发送事件（SSE）的 URL。
