# 核心节点库 <a href="#core-nodes-library" id="core-nodes-library"></a>

本节介绍 n8n 的核心节点[^1]。

[^1]: 在 n8n 中，节点是构建工作流的独立组件。节点定义工作流何时运行，支持获取、发送和处理数据，也可定义流程控制逻辑，并连接外部服务。
