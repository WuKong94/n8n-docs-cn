# Autopilot 触发器节点 <a href="#autopilot-trigger-node" id="autopilot-trigger-node"></a>

[Autopilot](https://www.autopilothq.com/) 是可视化营销软件，支持在整个客户旅程中实现营销自动化和个性化。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Autopilot 凭据文档](../credentials/autopilot.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Autopilot Trigger 集成](https://n8n.io/integrations/autopilot-trigger/)页面。
{% endhint %}

## 事件 <a href="#events" id="events"></a>

- Contact added（联系人已添加）
- Contact added to a list（联系人已加入列表）
- Contact entered to a segment（联系人已进入细分群组）
- Contact left a segment（联系人已离开细分群组）
- Contact removed from a list（联系人已从列表移除）
- Contact unsubscribed（联系人已退订）
- Contact updated（联系人已更新）
