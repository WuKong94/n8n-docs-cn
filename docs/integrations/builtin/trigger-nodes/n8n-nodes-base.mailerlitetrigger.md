# MailerLite 触发器节点 <a href="#mailerlite-trigger-node" id="mailerlite-trigger-node"></a>

[MailerLite](https://www.mailerlite.com/) 是电子邮件营销解决方案，提供易用的内容编辑器、简化的订阅者管理，以及包含关键统计数据的营销活动报告。

本页列出了 MailerLite Trigger 节点可响应的事件，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [MailerLite 凭据文档](../credentials/mailerlite.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [MailerLite Trigger 集成](https://n8n.io/integrations/mailerlite-trigger/)页面。
{% endhint %}

## 事件 <a href="#events" id="events"></a>

- Campaign Sent（营销活动已发送）
- Subscriber Added to Group（订阅者已加入群组）
- Subscriber Automation Completed（订阅者自动化已完成）
- Subscriber Automation Triggered（订阅者自动化已触发）
- Subscriber Bounced（订阅者邮件已退回）
- Subscriber Created（订阅者已创建）
- Subscriber Complained（订阅者已投诉）
- Subscriber Removed from Group（订阅者已从群组移除）
- Subscriber Unsubscribe（订阅者退订）
- Subscriber Updated（订阅者已更新）
