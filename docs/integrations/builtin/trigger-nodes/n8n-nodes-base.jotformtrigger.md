# Jotform 触发器节点 <a href="#jotform-trigger-node" id="jotform-trigger-node"></a>

[Jotform](https://www.jotform.com/) 是在线表单构建服务，提供拖放式表单创建工具，并可选择加密用户数据。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Jotform 凭据文档](../credentials/jotform.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Jotform Trigger 集成](https://n8n.io/integrations/jotform-trigger/)页面。
{% endhint %}
