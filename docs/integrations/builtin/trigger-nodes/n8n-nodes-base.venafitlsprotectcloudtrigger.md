# Venafi TLS Protect Cloud 触发器节点 <a href="#venafi-tls-protect-cloud-trigger-node" id="venafi-tls-protect-cloud-trigger-node"></a>

[Venafi](https://www.venafi.com/) 是提供机器身份管理服务的网络安全公司，支持管理和保护多种机器类型的身份，提供全局可见性、生命周期自动化和可指导行动的信息。

使用 n8n 的 Venafi TLS Protect Cloud Trigger 节点，响应[云端 Venafi TLS Protect](https://vaas.venafi.com/) 服务中的事件，启动 n8n 工作流。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Venafi TLS Protect Cloud 凭据文档](../credentials/venafitlsprotectcloud.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Venafi TLS Protect Cloud Trigger 集成](https://n8n.io/integrations/venafi-tls-protect-cloud-trigger/)页面。
{% endhint %}
