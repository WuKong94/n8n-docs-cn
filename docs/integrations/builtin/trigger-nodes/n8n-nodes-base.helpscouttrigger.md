# Help Scout 触发器节点 <a href="#help-scout-trigger-node" id="help-scout-trigger-node"></a>

[Help Scout](https://www.helpscout.com/) 是帮助台软件，为客户服务人员提供基于电子邮件的客户支持平台、知识库工具，以及可嵌入的搜索与联系组件。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Help Scout 凭据文档](../credentials/helpscout.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Help Scout Trigger 集成](https://n8n.io/integrations/helpscout-trigger/)页面。
{% endhint %}
