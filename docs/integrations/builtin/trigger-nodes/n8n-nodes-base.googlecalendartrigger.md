# Google Calendar 触发器 <a id="google-calendar-trigger"></a>

[Google Calendar](https://www.google.com/calendar/) 是 Google 开发的时间管理和日程安排日历服务。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Google 凭据文档](../credentials/google/README.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Google Calendar Trigger 集成](https://n8n.io/integrations/google-calendar-trigger/)页面。
{% endhint %}

## 事件 <a href="#events" id="events"></a>

* **Event Cancelled**（事件已取消）
* **Event Created**（事件已创建）
* **Event Ended**（事件已结束）
* **Event Started**（事件已开始）
* **Event Updated**（事件已更新）

[浏览 Google Calendar Trigger 集成模板](https://n8n.io/integrations/google-calendar-trigger)，或[搜索所有模板](https://n8n.io/workflows/)

## 相关资源 <a href="#related-resources" id="related-resources"></a>

n8n 为 Google Calendar 提供应用节点。更多信息请参阅 [Google Calendar 节点文档](../app-nodes/n8n-nodes-base.googlecalendar/README.md)。

在 n8n 网站查看[示例工作流和相关内容](https://n8n.io/integrations/google-calendar-trigger/)。

API 的详细信息，请参阅 [Google Calendar 文档](https://developers.google.com/calendar/api/v3/reference)。
