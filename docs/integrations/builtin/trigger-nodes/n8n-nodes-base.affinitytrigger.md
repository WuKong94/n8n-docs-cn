# Affinity 触发器节点 <a href="#affinity-trigger-node" id="affinity-trigger-node"></a>

[Affinity](https://www.affinity.co/) 是功能强大的人脉关系洞察平台，帮助团队利用人脉网络促成下一笔重要交易。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Affinity 凭据文档](../credentials/affinity.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Affinity Trigger 集成](https://n8n.io/integrations/affinity-trigger/)页面。
{% endhint %}
