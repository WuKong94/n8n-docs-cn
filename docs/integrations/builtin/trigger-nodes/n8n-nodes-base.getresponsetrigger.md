# GetResponse 触发器节点 <a href="#getresponse-trigger-node" id="getresponse-trigger-node"></a>

[GetResponse](https://www.getresponse.com/) 是提供电子邮件营销软件、落地页创建工具、网络研讨会托管等功能的在线平台。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [GetResponse 凭据文档](../credentials/getresponse.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [GetResponse Trigger 集成](https://n8n.io/integrations/getresponse-trigger/)页面。
{% endhint %}

## 事件 <a href="#events" id="events"></a>

- 客户订阅列表时接收通知
- 客户取消列表订阅时接收通知
- 邮件被打开时接收通知
- 邮件被点击时接收通知
- 问卷提交时接收通知
