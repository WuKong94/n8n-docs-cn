# Copper 触发器节点 <a href="#copper-trigger-node" id="copper-trigger-node"></a>

[Copper](https://www.copper.com/) 是注重与 Google Workspace 深度集成的 CRM，主要面向中小企业。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Copper 凭据文档](../credentials/copper.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Copper Trigger 集成](https://n8n.io/integrations/copper-trigger/)页面。
{% endhint %}

## 事件 <a href="#events" id="events"></a>

* Delete（删除）
* New（新增）
* Update（更新）
