# ActiveCampaign 触发器节点 <a href="#activecampaign-trigger-node" id="activecampaign-trigger-node"></a>

[ActiveCampaign](https://www.activecampaign.com/) 是面向中小企业的云软件平台，提供客户体验自动化软件，结合电子邮件营销、营销自动化、销售自动化和 CRM。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [ActiveCampaign 凭据文档](../credentials/activecampaign.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [ActiveCampaign Trigger 集成](https://n8n.io/integrations/activecampaign-trigger/)页面。
{% endhint %}
