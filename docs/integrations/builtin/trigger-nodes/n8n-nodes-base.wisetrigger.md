# Wise 触发器节点 <a href="#wise-trigger-node" id="wise-trigger-node"></a>

[Wise](https://wise.com) 提供低成本跨境汇款，可使用国际账户信息收款，并在手机上跟踪交易。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Wise 凭据文档](../credentials/wise.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Wise Trigger 集成](https://n8n.io/integrations/wise-trigger/)页面。
{% endhint %}

## 事件 <a href="#events" id="events"></a>

- 余额账户每次入账时触发
- 余额账户每次入账或扣款时触发
- 汇款的活跃案件列表每次更新时触发
- 汇款状态每次更新时触发
