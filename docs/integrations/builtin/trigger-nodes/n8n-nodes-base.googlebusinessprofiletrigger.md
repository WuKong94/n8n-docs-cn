# Google Business Profile 触发器节点 <a href="#google-business-profile-trigger-node" id="google-business-profile-trigger-node"></a>

使用 Google Business Profile Trigger 节点响应 [Google Business Profile](https://www.google.com/business/) 中的事件，并将其与其他应用集成。n8n 内置支持响应新增评价。

本页列出了 Google Business Profile Trigger 节点可响应的事件，并提供更多资源的链接。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Google 凭据文档](../credentials/google/README.md)。
{% endhint %}
