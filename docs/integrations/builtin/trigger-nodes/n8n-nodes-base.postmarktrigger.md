# Postmark 触发器节点 <a href="#postmark-trigger-node" id="postmark-trigger-node"></a>

[Postmark](https://postmarkapp.com) 帮助投递和跟踪应用邮件，可统计邮件发送或处理数量、打开次数、退信和垃圾邮件投诉等数据。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Postmark 凭据文档](../credentials/postmark.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Postmark Trigger 集成](https://n8n.io/integrations/postmark-trigger/)页面。
{% endhint %}
