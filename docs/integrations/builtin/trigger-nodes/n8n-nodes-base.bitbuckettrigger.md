# Bitbucket 触发器节点 <a href="#bitbucket-trigger-node" id="bitbucket-trigger-node"></a>

[Bitbucket](https://bitbucket.org/) 是 Atlassian 旗下基于网页的版本控制仓库托管服务，面向使用 Mercurial 或 Git 版本控制系统的源代码和开发项目。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Bitbucket 凭据文档](../credentials/bitbucket.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Bitbucket Trigger 集成](https://n8n.io/integrations/bitbucket-trigger/)页面。
{% endhint %}
