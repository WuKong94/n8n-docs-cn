# Keap 触发器节点 <a href="#keap-trigger-node" id="keap-trigger-node"></a>

[Keap](https://keap.com/) 是面向小企业的电子邮件营销和销售平台，提供客户生命周期管理与优化、客户关系管理、营销自动化、销售线索收集和电子商务等产品。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Keap 凭据文档](../credentials/keap.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Keap Trigger 集成](https://n8n.io/integrations/keap-trigger/)页面。
{% endhint %}
