# Mailjet 触发器节点 <a href="#mailjet-trigger-node" id="mailjet-trigger-node"></a>

[Mailjet](https://www.mailjet.com/) 是基于云的邮件发送和跟踪系统，可发送营销邮件和事务性邮件，提供邮件设计、大批量发送和消息跟踪工具。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Mailjet 凭据文档](../credentials/mailjet.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Mailjet Trigger 集成](https://n8n.io/integrations/mailjet-trigger/)页面。
{% endhint %}
