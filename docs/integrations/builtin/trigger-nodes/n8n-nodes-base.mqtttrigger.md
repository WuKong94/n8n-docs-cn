# MQTT 触发器节点 <a href="#mqtt-trigger-node" id="mqtt-trigger-node"></a>

[MQTT](https://mqtt.org) 是开放的 OASIS 和 ISO 标准，也是一种轻量级发布订阅网络协议，用于在设备之间传输消息。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [MQTT 凭据文档](../credentials/mqtt.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [MQTT Trigger 集成](https://n8n.io/integrations/mqtt-trigger/)页面。
{% endhint %}
