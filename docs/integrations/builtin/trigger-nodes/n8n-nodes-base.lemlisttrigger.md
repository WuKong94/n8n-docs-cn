# Lemlist 触发器节点 <a href="#lemlist-trigger-node" id="lemlist-trigger-node"></a>

[Lemlist](https://Lemlist.com) 是电子邮件外联平台，可自动生成个性化图片和视频，并发送个性化的陌生客户开发邮件。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Lemlist 凭据文档](../credentials/lemlist.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Lemlist Trigger 集成](https://n8n.io/integrations/lemlist-trigger/)页面。
{% endhint %}
