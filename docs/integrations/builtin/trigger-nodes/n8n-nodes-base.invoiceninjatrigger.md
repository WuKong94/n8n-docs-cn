# Invoice Ninja 触发器节点 <a href="#invoice-ninja-trigger-node" id="invoice-ninja-trigger-node"></a>

[Invoice Ninja](https://www.invoiceninja.com/) 是面向自由职业者和企业的免费开源在线开票应用，提供发票、收款、费用跟踪及计时任务功能。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Invoice Ninja 凭据文档](../credentials/invoiceninja.md)。
{% endhint %}

**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Invoice Ninja Trigger 集成](https://n8n.io/integrations/invoice-ninja-trigger/)页面。
{% endhint %}
