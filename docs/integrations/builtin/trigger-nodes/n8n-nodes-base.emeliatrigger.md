# Emelia 触发器节点 <a href="#emelia-trigger-node" id="emelia-trigger-node"></a>

[Emelia](https://emelia.io) 是一款陌生客户邮件营销工具。

{% hint style="info" %}
**凭据**

此节点的身份验证信息，请参阅 [Emelia 凭据文档](../credentials/emelia.md)。
{% endhint %}

{% hint style="info" %}
**示例与模板**

入门用法示例和模板，请参阅 n8n 的 [Emelia Trigger 集成](https://n8n.io/integrations/emelia-trigger/)页面。
{% endhint %}

## 事件 <a href="#events" id="events"></a>

- Email Bounced（邮件已退回）
- Email Opened（邮件已打开）
- Email Replied（邮件已回复）
- Email Sent（邮件已发送）
- Link Clicked（链接已点击）
- Unsubscribed Contact（联系人已退订）
