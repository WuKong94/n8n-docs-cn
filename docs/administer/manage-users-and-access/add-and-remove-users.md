# 管理用户 <a href="#manage-users" id="manage-users"></a>

**Settings**（设置）> **Users**（用户）页面显示所有用户，包括邀请尚待接受的用户。

## 删除用户 <a href="#delete-a-user" id="delete-a-user"></a>

1. 打开待删除用户的**三点菜单**，选择 **Delete user**（删除用户）。
2. 确认删除。
3. 如果用户已激活，请选择将其工作流数据和凭据复制给新用户，或永久删除其工作流和凭据。

## 向待接受邀请的用户重新发送邀请 <a href="#resend-an-invitation-to-a-pending-user" id="resend-an-invitation-to-a-pending-user"></a>

点击用户旁的菜单图标，再点击 **Resend invite**（重新发送邀请）。
