# 验证用户身份 <a href="#verify-user-identity" id="verify-user-identity"></a>

确认登录 n8n 实例的用户身份，支持双因素身份验证及基于目录服务的单点登录。

## 本节内容 <a id="in-this-section"></a>

* [要求双因素身份验证](require-two-factor-auth.md)：为你的 n8n 账号启用 2FA。
* [连接 LDAP](connect-ldap.md)：在 n8n 中使用 LDAP。
* [使用 SAML](use-saml/README.md)：在 n8n 中启用 SAML SSO（单点登录）。
* [使用 OIDC](use-oidc/README.md)：启用 OpenID Connect（OIDC）进行单点登录。
