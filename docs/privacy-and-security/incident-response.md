# 事件响应 <a href="#incident-response" id="incident-response"></a>

n8n 采用事件响应最佳实践，识别、记录和解决事件，并就事件进行沟通。

n8n 在 [n8n Status](https://status.n8n.cloud/) 状态页面发布事件通知。

n8n 按照公司的[数据处理附录](https://n8n.io/legal/#data)向客户通知数据泄露事件。
